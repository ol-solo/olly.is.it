# Работа с файлами. Практика

Управление контекстом:

- `with open(filename, mode) as file:` — управляет контекстом для работы с файлами, автоматически закрывая файл после выполнения операций.

Параметры функции `open`:

- `mode='r'` — открывает файл в режиме чтения (read). Файл должен существовать, иначе будет вызвана ошибка.
- `mode='w'` — открывает файл в режиме записи (write). Если файл уже существует, его содержимое будет стерто. Если файл не существует, он будет создан.

После открытия файла, являющегося архивом, получить доступ к файлу внутри архива можно через метод `zipfile.ZipFile(filename, mode)`. Используйте режим `'r'` для чтения архива и `'w'` для его создания или перезаписи.

## Задание 1.

Дан текст и файл, в который этот текст нужно записать. Запишите текст в файл, используя оператор контекста `with`.

```python
FILE_NAME = 'new_file.txt'
text_table = '''
```


## Задание 3.

Найдите в папке `/datasets/` все файлы, начинающиеся на `'megaline_'` и кончающиеся на `'.csv'` и запакуйте их в архив `'megaline_archive.zip'` методом `ZIP_DEFLATED`. Выведите полный путь к файлу из названия файла и пути к папке.

```python
import os
import zipfile
  
ZIPARCHIVE = 'megaline_archive.zip'
  
def percentation(number):
    if type(number) not in [int, float]:
        return "NaN"
    else:
        return str(round(number,3)*100)[:4] + "%"
data_dir = '/datasets/'
  
with zipfile.ZipFile('megaline_archive.zip', 'w', zipfile.ZIP_DEFLATED) as archive:
    for f in os.listdir(data_dir):
        if f.startswith('megaline_') and f.endswith('.csv'):
            full_path = os.path.join(data_dir, f)
            archive.write(full_path)
  
  
with zipfile.ZipFile(ZIPARCHIVE, 'r') as archive:
#    archive.printdir()
    print(*[file.filename + ":\t" + percentation(file.compress_size/file.file_size)
            for file in archive.infolist()],sep="\n")
```

# Работа с таблицами. Практика

## **Шпаргалка**

`pd.read_html(url, header=0)` — функция для извлечения таблиц из HTML-контента по указанному URL. Параметр `header=0` указывает, что первая строка таблицы содержит заголовки столбцов.

`df.to_excel('file.xlsx', index=False, sheet_name='Sheet1', engine='openpyxl')` — метод для сохранения DataFrame в файл Excel. Параметр `index=False` указывает не сохранять индексы строк, `sheet_name` задает имя листа, `engine='openpyxl'` необходим для сохранения стилей.

# Подготовка графики. Практика

В этом уроке вы попрактикуетесь в подготовке визуализаций к сохранению в виде отдельного файла.

Вы решите несколько задач:

- построите график месячной динамики изменения денежных вложений в основные источники привлечения пользователей развлекательного приложения;
- добавите оформление графика — заголовок, подписи по осям;
- сохраните визуализацию в виде отдельного графического файла формата PNG;
- создадите субплот с двумя графиками: месячной и недельной динамиками изменения затрат на рекламные источники — и сохраните его в виде графического файла в формате SVG.

Для построения графиков используйте библиотеку seaborn. При оформлении графика вам могут пригодиться такие методы и их аргументы:

|**Метод / аргумент**|**Описание**|
|---|---|
|plt.figure()|Создание контейнера для графика|
|plt.figure(figsize=())|Создание контейнера для графика заданного размера|
|plt.subplots()|Создание контейнера для нескольких графиков (субплотов)|
|plt.title()|Создание заголовка для графика|
|plt.xlabel() и plt.ylabel()|Создание подписей осей x и y|
|.set_title(), .set_xlabel() и .set_ylabel()|Применяются к элементу ax для создания заголовка субплота и подписей по осям|
|plt.xticks(rotation=)|Метод, позволяющий заменять оформление меток по осям, где аргумент rotation поворачивает подписи по оси x на переданный аргументу угол|
|plt.yticks(rotation=)|Метод, позволяющий заменять оформление меток по осям, где аргумент rotation поворачивает подписи по оси y на переданный аргументу угол|
|plt.grid()|Добавляет для графика сетку|
|plt.tight_layout()|Позволяет автоматически разместить элементы графиков между собой, чтобы они не накладывались друг на друга|
|plt.savefig()|Позволяет сохранить график в виде графического файла|

Для построения необходимых визуализаций используйте данные `costs_info_short.csv`, содержащие информацию о затратах на рекламные вложения по каждому рекламному источнику:

- `dt` — дата совершения затрат;
- `Channel` — название рекламного источника привлечения новых пользователей;
- `costs` — сумма затрат в условных единицах.

## Задание 1.

Изучите месячную динамику изменения затрат на привлечение новых пользователей по каждому рекламному источнику.

Для этого загрузите данные, добавьте дополнительный столбец с месяцем затрат, затем сгруппируйте данные для каждого источника и по месяцам, рассчитайте суммарные затраты.

При агрегации данных используйте методы `groupby` и `agg`. Это позволит создать длинную, или вертикальную, таблицу, которую будет удобно использовать при визуализации данных в seaborn. Агрегированные данные сохраните в переменной `m_result`.

Используя полученные данные, постройте линейный график динамики затрат, где по оси `x` отложите месяц затрат, а по оси `y` — общую сумму затрат по каждому рекламному источнику. Для построения графика используйте библиотеку seaborn. Полученную визуализацию выведите на экран.

В этом задании можно построить базовую версию визуализации — добавлять подписи по осям, заголовок графика и менять размер визуализации не нужно. Это вы сделаете в следующем задании.

```python
# Импортируем необходимые библиотеки:
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
  
# Загрузим данные:
costs = pd.read_csv('/datasets/costs_info_short.csv')
  
# Скорректируем тип данных в столбце с датой затрат:
costs['dt'] = pd.to_datetime(costs['dt'])
  
# Создадим столбец с месяцем затрат:
costs['month'] = costs['dt'].dt.month
  
# Сгруппируем данные и рассчитаем суммарные месячные затраты для каждого источника:
m_result = costs.groupby(['Channel', 'month']).agg({'costs': 'sum'}).reset_index()
  
# Выведем первые пять строк на экран:
print(m_result.head())
  
# Визуализируем результаты:
sns.lineplot(data=m_result, x='month', y='costs', hue='Channel')
  
plt.show()
```
