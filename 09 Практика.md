# Выделяем когорты. Практика

В этом уроке вы потренируетесь в применении функций `first()` и `last()` для поиска первых признаков пользователей, а также создадите профиль пользователя международного интернет-магазина электронных книг «Читать не вредно».

При использовании `first()` и `last()` важно в начале провести сортировку данных по дате совершения события и только потом применять эти методы. При этом важно учитывать направление сортировки данных — по возрастанию значений или по уменьшению. Если сортировка по возрастанию, т.е. значение параметра `ascending=True` метода `.sort_values()` — по умолчанию, то тогда стоит использовать `first()`. Если сортировка обратная — от большего к меньшему `ascending=False` — то использовать `last()`.

## Задание 1.

Выясните, в каком году и на какой платформе впервые вышли три игры: `Grand Theft Auto V`, `Super Mario Bros.` и `The Sims 2`.

Для этого загрузите данные файла `/datasets/three_more_games.csv`, отсортируйте их, выполните группировку и выведите результат на экран. При решении используйте функцию `first()`.

Данные содержат следующие столбцы:

- `name` — название игры;
- `platform` — название платформы;
- `year` — год релиза.

```python
# Импортируем необходимые библиотеки:
import pandas as pd
  
# Загрузим и подготовим данные для последующей группировки:
games = pd.read_csv('/datasets/three_more_games.csv')
games = games.sort_values(by=['name', 'year'])
  
# Выполнем группировку данных:
result = games.groupby('name').agg({'year': 'min', 'platform': 'first'})
  
# Выведем результат на экран:
print(result)
```
