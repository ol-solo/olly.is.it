## 1.Агрегация. Практика

В модуле вы разобрали методы **pandas**, которые позволяют получить полезную для анализа данных информацию: количество строк в таблице (атрибут датафрейма `shape`), количество значений в столбцах (`.count()`), уникальные значения (`.unique()`) и их количество (`.nunique()`), а также распределение данных по ним (`.value_counts()`). Помимо этого, вы познакомились с методами, которые позволяют подсчитать сумму значений в столбце (`.sum()`), а также изучить разброс данных и найти минимальное (`.min()`) и максимальное (`.max()`) значения, среднее (`.mean()`) и медиану (`.median()`).

В этом уроке продолжим тренироваться использовать эти методы для решения практических задач. Помогут нам в этом данные о покупках в сети магазинов строительных материалов — датасет `/datasets/retail_dataset.csv`, содержащий следующие данные:

- `purchaseId` — id чека;
- `item_ID` — id товара;
- `purchasedate` — дата покупки;
- `Quantity` — количество товара;
- `CustomerID` — id покупателя;
- `ShopID` — id магазина;
- `loyalty_program` — участвует ли покупатель в программе лояльности.

Проведём небольшой анализ данных:

- загрузим данные, изучим первые строки и оценим объём строк и значений в столбцах;
- определим период сбора информации;
- найдём количество уникальных значений в данных;
- подсчитаем количество торговых точек и распределение покупок по ним;
- изучим разброс значений по количеству проданного товара в каждой покупке.

Старайтесь добавлять код только там, где указано `# напишите ваш код здесь`.

Задание 1.

Пришло время узнать информацию о магазинах. Подсчитайте общее количество торговых точек (`ShopID`) и выведите на экран их уникальные id в виде списка. После этого подсчитайте количество проданных товаров на одну торговую точку.

```python
# Импортируем необходимые библиотеки:
import pandas as pd
  
# Загрузим данные из источника /datasets/retail_dataset.csv:
retail = pd.read_csv('/datasets/retail_dataset.csv')
  
# Найдём уникальное количество торговых точек:
print('Уникальное количество торговых точек:', retail['ShopID'].nunique())
  
# Выведем уникальные id торговых точек:
print('Уникальное id торговых точек:', retail['ShopID'].unique())
  
# Подсчитаем среднее количество проданных товаров на одну торговую точку:
item_num_per_shop = retail['Quantity'].sum() / retail['ShopID'].nunique()
print(f'Среднее количество проданных товаров на одну торговую точку: {item_num_per_shop:.2f}')
```

Задание 3.

Осталось посмотреть, в каком количестве продаются товары в магазинах. Для этого оцените разброс значений в столбце `Quantity`: найдите минимальное и максимальное количество проданных товаров в одном чеке, а также среднее значение и медиану.

```python
# Импортируем необходимые библиотеки:
import pandas as pd
  
# Загрузим данные из источника /datasets/retail_dataset.csv:
retail = pd.read_csv('/datasets/retail_dataset.csv')
  
# Оценим разброс значений по количеству проданного товара в одном чеке:
print('Минимальное количество проданных товаров в одном чеке:', retail['Quantity'].min())
print('Максимальное количество проданных товаров в одном чеке:', retail['Quantity'].max())
print('Среднее количество проданных товаров в одном чеке:', retail['Quantity'].mean())
print('Медианное количество проданных товаров в одном чеке:', retail['Quantity'].median())
```

## 3.Базовая проверка данных

В работе с данными почти всегда вас ждут сюрпризы:

- Почему-то выгрузили не те данные или не всё, что есть.
- Ошибки в алгоритмах, считающих заезды: скажем, время заправки учли неверно.
- Не тот формат: например, вместо секунд записали минуты.
- Упущен какой-нибудь существенный факт. Так, водители могли заехать на нерабочую АЗС (а счётчик их учёл) и развернуться, не заправившись (счётчик зафиксировал очень короткое время).

Словом, в данных может быть всё что угодно. Именно вы как аналитик ручаетесь за их реалистичность. Попробуйте оценить, насколько они достоверны. Начните с базовых проверок. Например, можно ответить на вопросы:

- Сколько всего заездов зафиксировано за время исследования?
- Сколько АЗС?
- Сколько заездов на одну АЗС в день?
- Какие сети АЗС самые популярные?

...И самостоятельно либо с помощью коллег оценить, похожи ли результаты ваших расчётов на правду.

Базовая проверка может обнаружить проблему в данных. Или наоборот — свидетельствовать, что с ними всё в порядке. По крайней мере, пока.
