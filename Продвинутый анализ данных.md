# Получение и сохранение данных
## Работа с файлами
В процессе работы бывает нужно проанализировать произвольные файлы с текстовой информацией или поработать с файлами внутри архива. В этом уроке мы узнаем, как функция `open` помогает читать и записывать файлы, научимся работать с файловой системой, а также поймём, как работать с архивными файлами через модуль `zipfile`. Это поможет понять, как аналитики могут организовывать и хранить данные.

### Открываем файлы

Функция `open` в Python используется для открытия файла. Она обращается к файловой системе и создаёт объект, который предоставляет методы для чтения или записи. Эта функция принимает два основных аргумента: имя файла и режим открытия, такой как `'r'` (read) для чтения, `'w'` (write) для полной перезаписи содержимого файла или его создания, `'a'` (append) для того, чтобы добавить содержимое в конец файла. Открыть и прочитать содержимое небольшого файла можно так:

```
file = open('example.txt', 'r')
content = file.read()
print(content)
file.close() 
```

В этом случае после чтения содержимого файла связанный с ним объект необходимо закрыть вызовом `file.close()` для освобождения системных ресурсов. Так вы показываете программе, что больше не будете обращаться к файлу.

Конструкция `with...as` упрощает управление файлами, обеспечивая автоматическое закрытие файла после выхода из блока `with`. Это делает код более чистым и безопасным:

```
with open('example.txt', 'r') as file:
    content = file.read()
    print(content) 
```

Этот код имеет такое же действие, как и код выше. Здесь файл автоматически закрывается после завершения чтения, и не нужно беспокоиться о закрытии файла вручную.

### Создаём текстовый файл

Иногда бывает необходимо создать файл с произвольным содержимым и сохранить его на диск. Откроем и перезапишем или создадим файл при помощи функции`open` в режиме записи (`"w"`) и сохраним в него имеющийся у нас текст:

```
content = """Ежедневный отчёт по продажам:
Дата: 21 мая 2024 года
Общее количество продаж: 150
Общая сумма продаж: 25,000

Основные категории товаров:
1. Электроника - 50 продаж
2. Одежда - 30 продаж
3. Бытовая техника - 70 продаж

Замечания:
- Увеличение продаж бытовой техники на 20% по сравнению с предыдущим днём.
- Снижение продаж одежды на 10%."""

with open('example.txt', 'w') as file:
    file.write(content) 
```

В данном случае создаётся файл `example.txt` и в него записывается текст из переменной `content`. Функция `write` записывает текст в файл, а использование конструкции `with...as` нужно, чтобы файл корректно закрылся после завершения записи.

### Построчная обработка данных

Не всегда полностью читать файл это хорошая идея, особенно если файл очень большой. У нас есть логи сервера `server.log`, если логи собираются за длительный срок, они могут достигать значительных объёмов. Чтобы понять, как автоматически проанализировать логи построчно, откроем такой файл со следующим содержимым:

```
2024-05-14 08:00:00 INFO Server started.
2024-05-14 08:15:23 ERROR Failed to connect to database.
2024-05-14 09:00:17 INFO New user registered.
2024-05-14 09:17:45 ERROR Timeout occurred processing request. 
```

Для того, чтобы перебрать строки файла, необходимо начать цикл, итерируясь по объекту файла. Внутри цикла мы перебираем каждую строку файла, проверяя наличие слова "ERROR". Если строка содержит это слово, она добавляется в список `errors` после удаления пробелов и символов новой строки с помощью метода `strip()`. В полученном списке подсчитываем число элементов и выводим его на экран:

```
errors = []
with open('server.log', 'r') as file:
    for line in file:
        if "ERROR" in line:
            errors.append(line.strip())

print(f"Найдено ошибок: {len(errors)}") 
```

```
Всего ошибок в логах: 2 
```

### Открываем много файлов

Не всегда мы знаем точно название файла, который нам нужно открыть. Также, зачастую в процессе работы приходится иметь дело не с одним и не с двумя файлами, а с большим их количеством. Например, каждый день филиал присылает файл, имя которого начинается с `report_` и заканчивается на `.xlsx` и нам нужно обработать все эти файлы. Сначала найдём все такие файлы. В этом нам поможет библиотека `os`. Её метод `listdir` позволяет получить содержимое указанной папки. Строкой из одной точки обычно обозначается текущая папка.

```
import os

reports = [f for f in os.listdir('.') 
            if f.startswith('report_') and f.endswith('.xlsx')] 
```

В переменную `reports` теперь помещён список названий файлов `['report_2024-05-06.xlsx', 'report_2024-05-07.xlsx', 'report_2024-05-08.xlsx', 'report_2024-05-09.xlsx', 'report_2024-05-10.xlsx']` с названиями ежедневных отчётов за предыдущую неделю. Теперь мы можем обработать их в цикле необходимым образом.

Для открытия отчётов нам потребуется метод Pandas `read_excel`. Отчёт типовой, сверху у него шапка, снизу место для подписей сотрудников, посередине данные. Пропустить строки шапки нам поможет параметр `skiprows`, он принимает список строк, начиная с нуля, которые нужно пропустить. Пропустить окончание документа нам поможет параметр `skipfooter`, он принимает одно число — количество строк в конце документа, которые не нужно загружать.

У отчёта много объединённых ячеек и не каждый столбец содержит данные. Так как нужные нам столбцы у отчёта не меняются, мы указываем их в нотации Excel в параметре `usecols`, где можем использовать как отдельные столбцы, так и их диапазоны. После загрузки отчёта метод `set_axis` с параметром `axis=1` позволит нам задать названия столбцам загружаемого датафрейма. Важно изменять список новых названий согласованно со значением, передаваемым в `usecols`. Весь пример кода загрузки датасетов в цикле целиком:

```
import pandas as pd

# Для каждого названия файла отчёта
for report in reports:
    # Открываем файл с таблицей
    df_raw = pd.read_excel(
        report,
        # Пропускаем шапку отчёта из 35 строк
        skiprows=range(35),
        # Пропускаем последние 10 строк документа
        skipfooter=10,
        # Используем заранее известные столбцы
        usecols="K:L,AY,BF,BU,CJ")\
        .set_axis(
            # Задаём названия оси таблицы 
            [   "Раздел", 
                "Показатель", 
                "Код показателя", 
                "Текущий год", 
                "Предыдущий год", 
                "Предшествующий предыдущему"],
            # Заменяем названия колонок
            axis=1) 
```

Далее нам может потребоваться предобработка данных и расчёт каких-то показателей. Информацию можно брать не только из таблицы: само имя файла `report` у нас содержало дату — её можно извлечь и сохранить, чтобы потом анализировать динамику метрик.

### Работаем с архивами

Библиотека `zipfile` в Python предоставляет возможности для работы с ZIP-архивами, включая возможности их создания, чтения, записи, а также извлечения содержимого. Допустим, что в конце предыдущего раздела мы подготовили сводный отчёт и сохранили его на диске под названием `consolidated_report.xlsx`. Этот файл вместе с отчётами за отдельные дни нам нужно добавлять в архив. Так как предыдущие действия мы автоматизировали, попробуем автоматизировать и это! Помня, что файлы продолжают лежать в той же папке, в которой мы запускаем скрипт, сделаем это при помощи модуля `zipfile`:

```
import zipfile

with zipfile.ZipFile('reports_archive.zip', 'w', zipfile.ZIP_DEFLATED) as archive:
    for report in reports:
        archive.write(report)
    else:
        archive.write('consolidated_report.xlsx') 
```

Конструкция `else` после циклов отрабатывает в случае успешного завершения цикла. Ура, теперь всё сохранили, можем отсылать! Обратите внимание, `zipfile` по умолчанию не сжимает файлы при создании архива, поэтому мы указываем тип сжатия `zipfile.ZIP_DEFLATED`.

### Автоматизация процессов с помощью чтения ZIP-архивов

Текстовые форматы хранения данных, например формат `csv`, могут очень быстро прибавлять в объёме по мере добавления данных, но они обычно хорошо сжимаются. Очень часто такие файлы распространяются в запакованном виде.

Выше мы записывали файлы в архив, но архивы иногда бывает необходимо читать. Используем библиотеку `zipfile` для этого.

Для более надёжной и безопасной работы с файлами и архивами используем использовавшуюся выше конструкцию `with...as`, причём сделаем её вложенной. Конструкция гарантирует, что файл и архив будут корректно закрыты после завершения нужных операций.

Например, внутри архива расположен файл `purchases.csv`, который выглядит следующим образом:

```
PurchaseID,Amount
001,25.50
002,45.00
003,17.75
004,34.00 
```

Используем модуль `zipfile` для открытия архива `monthly_data.zip` с помощью конструкции `with...as`. Затем внутри архива открываем файл `purchases.csv`. Первую строку файла, содержащую заголовки, проверяем с помощью функции `next(file)` и конструкции `assert` на соответствие ожидаемому значению. В случае несоответствия заголовков `assert` выведет сообщение об ошибке. Файл для Python — это набор байтов, как и отдельные его части, поэтому мы ставим `b` перед строкой.

Используя генераторное выражение внутри функции `sum`, подсчитываем количество строк, которое соответствует количеству покупок. В конце результат выводится на экран.

```
import zipfile

# Открытие ZIP-архива и чтение содержимого CSV-файла внутри
with zipfile.ZipFile('purchases.zip', 'r') as archive:
    with archive.open('purchases.csv') as file:
        assert next(file) == b'PurchaseID,Amount\n', \
            'Заголовки файла не соответствуют ожидаемым'
        # Подсчёт количества строк и покупок
        total_purchases = sum(1 for _ in file)

print(f"Общее количество покупок: {total_purchases}") 
```

Мы научились добавлять файлы в архивы и открывать текстовые файлы в Python, даже если они запакованы. Если есть возможность импортировать библиотеку pandas и в архиве лежит всего один файл csv, то можно использовать привычный метод `read_csv`. Однако для других случаев удобно знать другие методы открытия текстовых данных.

### Запуск кода

C тем, **какой** код запускать мы разобрались, но чтобы автоматизация была удобной, надо придумать, **как** его запускать. Работа в Python может быть весьма разнообразной, как и задачи, которые решаются с его помощью.

Основными форматами файлов в Python считаются `.py`, они используются для создания и запуска собранных программ и проектов. Файлы `.ipynb` применяются для интерактивного выполнения кода и ведения журнала вычислений в удобном интерфейсе Jupyter Notebook, так как они удобнее для написания кода, особенно если его нужно кому-то передавать. Однако для запуска небольшого скрипта тетрадки Jupyter Notebook подходят хуже.

Если скрипт выше сохранён в файле `purchases.py` и на компьютере установлен Python, то достаточно в командной строке ввести `python purchases.py`, чтобы увидеть результат: `Общее количество покупок: 4`.

Вы можете использовать подходящие для вашей системы планировщики запуска скриптов для автоматизации рабочих задач.

## Работа с таблицами
Аналитика начинается с данных. Бывает, что они хранятся уже в готовых csv/tsv-файлах и вы используете метод `read_csv()`, чтобы превратить таблицы в датафреймы. Бывает, что данные хранятся в Excel-файле, но и это уже нестрашно и вы вызываете метод `read_excel()`.

Так или иначе, всё это время вы работали с таблицами, которые хранятся на вашем компьютере, перед этим скачивая их по ссылке.

Но что делать, если таблица с данными, которые вам нужны, хранится где-то в интернете, на веб-странице, а кнопки `скачать` просто нет?

### Сайты тоже хранят данные

Переходя по ссылке на любой из сайтов, ваш браузер всегда начинает с того, что скачивает файлы, это называют загрузкой сайта. Все файлы, которые скачивает браузер, делятся на несколько типов, вот самые важные:

- `html` — получая такой файл, браузер понимает, как должна выглядеть страница сайта для пользователя, и начинает её отрисовку. `html`-файл говорит браузеру, как именно нарисовать страницу сайта и что она будет содержать. По сути, это разметка с содержимым, как Markdown в jupyter-третрадке, но посложнее. Именно об этом файле мы сегодня поговорим.
- `png/jpg/gif` и прочее — это картинки, которые сопровождают вас почти всегда: логотип сайта, видеолендинг. Это называют ассетами.
- `js` — это те файлы, которые говорят браузеру, что нужно делать, когда начинаете взаимодействовать с сайтом: кликать, скроллить или печатать.

Всё содержимое страницы сайта хранится в `html`-файле, и выглядит он примерно так:

```
<!DOCTYPE html>
<html>
<head>
  <title>Мой первый веб-сайт</title>
</head>
<body>
  <header>
    <h1>Добро пожаловать на мой сайт!</h1>
    <nav>
      <ul>
        <li><a href="#">Главная</a></li>
        <li><a href="#">О нас</a></li>
        <li><a href="#">Услуги</a></li>
        <li><a href="#">Контакты</a></li>
      </ul>
    </nav>
  </header>
  
... 
```

Попробуем прочитать эти данные прямо с сайта, но используя Pandas. Для этого воспользуемся методом `read_html()`, указывая параметром только адрес URL-ссылки на страницу. Этот метод исследует html-файл страницы и пытается найти всё, что похоже на таблицу, и превратить в датафрейм. Строку подаём сразу в зашифрованном виде (`%D0%A7`…), скопировав из адресной строки браузера.

```
import pandas as pd

tables = pd.read_html('https://ru.wikipedia.org/wiki/%D0%A7%D0%B5%D0%BC%D0%BF%D0%B8%D0%BE%D0%BD%D0%B0%D1%82_%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D0%B8_%D0%BF%D0%BE_%D1%84%D1%83%D1%82%D0%B1%D0%BE%D0%BB%D1%83')
```

## Подготовка графики

Для использования графиков в документах важно корректно их сохранить в файле с графическим форматом, чтобы визуализация была информативной и правильно оформленной. В прошлых уроках вы узнали, какие элементы стоит отобразить на графике, чтобы он был максимально информативным: задать заголовок, подпись по осям, легенду и другую необходимую информацию. Ещё вы изучили, как изменить размер графика, сохранить визуализацию в отдельном графике, выбрать корректный формат и разрешение файла, а также настроить отображение всех элементов графика.

В этом уроке мы рассмотрим особенности отображения и сохранения визуализаций в виде отдельных графических файлов:

- как настроить размер шрифтов;
- как вместить все элементы графика в сохраняемую область и избежать их пересечения;
- как сохранить график в виде отдельного файла, выбрав его разрешение и формат.

Для примера будем использовать графики с динамикой кумулятивных метрик, которые вы разбирали в предыдущих спринтах.

### Меняем размер графика и размер шрифта

В текстовый файл или презентацию графические файлы вставляются в виде изображения с заданным размером — в сантиметрах или дюймах. А также с установленным разрешением — количеством точек на дюйм.

По умолчанию графики, построенные с использованием распространённых библиотек визуализаций matplotlib и seaborn, имеют размер 6.4 на 4.8 дюйма, или примерно 16 на 12 см. Этого размера хватит, чтобы вставить визуализацию в текст на странице формата А4 или в страницу презентации. При работе с данными в тетрадке Jupyter Notebook размеры графиков часто увеличивают — это повышает информативность визуализации. Для этого используют параметр `figsize=()` метода `plt.figure()`, где задаются два значения: первое — размер графика по ширине, а второе — размер по высоте. Размеры задают в дюймах.

При подготовке графика к публикации следует не ставить размер больше свободного места на странице текста или слайде в презентации, поскольку в этом случае визуализация будет масштабирована под размер страницы. Как правило, для текстовых файлов используется лист формата А4, имеющий размер 210 на 297 мм, или 8.3 на 11.7 дюймов. Поэтому с учётом полей страницы желательно, чтобы размер сохраняемого графика не превышал 18 см по ширине страницы и 27 см по её высоте.

В большинстве случаев текстовые документы имеют альбомную ориентацию — можно взять за ограничение ширины графика 18 см, или около 7 дюймов по ширине. В таком случае задаваемые размеры шрифтов для подписи заголовка графика или его осей будут соответствовать распространённым размерам шрифтов в текстовых редакторах.

Разберём на примере графика кумулятивного значения среднего количества покупок на покупателя. Вначале рассчитаем необходимые метрики:

```
# Импортируем необходимые библиотеки:
import pandas as pd
from matplotlib import pyplot as plt
import seaborn as sns

# Загрузим данные с результатом теста:
orders = pd.read_csv('https://code.s3.yandex.net/datasets/orders_us.csv')
orders['date'] = pd.to_datetime(orders['date'])

# Найдём минимальную и максимальную даты сбора статистики:
start_date = orders['date'].min()
end_date = orders['date'].max()

# Создадим последовательность дат проведения теста:
test_dates = pd.date_range(start=start_date, end=end_date, freq='1D')

# Создадим пустой датафрейм с двумя столбцами — группами теста:
cum_avg_purchases = pd.DataFrame(columns = ['A', 'B'])

# Зададим цикл, перебирающий последовательность дат:
for i, date in enumerate(test_dates):
    current_purchases = (orders.query('date <= @date')
         # Для каждого пользователя в группах найдём количество заказов:
          .groupby(['group','visitorId'])
          .agg({'transactionId': 'nunique'}).reset_index()
         # Для каждой группы подсчитаем среднее количество заказов:
          .groupby('group')
          .agg({'transactionId': 'mean'}).T
        )

    # Добавим информацию о дате и дне проведения теста:
    current_purchases['date'] = date
    current_purchases['test_day'] = i

    # Добавим данные к датафрейму cum_revenue:
    cum_avg_purchases = pd.concat([cum_avg_purchases, current_purchases],
                                  ignore_index=True)

# Подсчитаем относительное значение метрики в группе В по отношению к группе А
cum_avg_purchases['rel_BA'] = cum_avg_purchases['B'] / cum_avg_purchases['A'] - 1 
```

А затем начнём строить график динамики отношения значений кумулятивного количества заказов на пользователя в группе В по отношению к группе А. Зададим размер графика, равный 7 на 4 дюйма:

```
# Визуализируем результаты:
plt.figure(figsize=(7, 4))
sns.lineplot(x='date', 
             y='rel_BA', 
             data=cum_avg_purchases, 
             label='Отношение группы В к группе А')

plt.show() 
```

### Сохранение графика

График готов. Для дальнейшего использования его стоит сохранить в виде отдельного графического файла.

Графические данные могут быть представлены в различных форматах:

- Растровое изображение, представленное в виде набора пикселей и раскрашенное в определённые цвета. Например, если размер картинки 100 на 100 пикселей, то изображение будет состоять из 100х100 или 10 000 пикселей. В таком формате хранится большая часть изображений, например фотографии в телефоне.
- Векторное изображение, для которого прописаны правила отображения: с такого-то места до такого провести линию синего цвета или в таком месте нарисовать красный круг заданного диаметра. Такой формат хорошо подходит для отображения схематичных рисунков или графиков.

Графики в Python можно сохранить изображение как в растровом, так и в векторном виде:

- в растровом виде, например с расширением `png` или `jpg`;
- в векторном формате `svg`;
- В формате `pdf`.

Для сохранения визуализации, созданной на основе matplotlib, используется метод `plt.savefig()`. Для быстрого сохранения графика с базовыми настройками достаточно передать методу в качестве аргумента название файла:

```
# Сохраним визуализацию в формате PNG: 
plt.savefig("my_first_plot.png")  
```

Визуализация сохранилась с базовыми настройками в файл, расположенный в корневом каталоге тетрадки Jupyter Notebook. Метод `plt.savefig()` имеет ещё несколько параметров, которые могут быть полезными при сохранении визуализаций:

- `dpi` — параметр задаёт размер разрешения — количества точек дюйм. Чем выше это значение — тем более чёткое изображение, но и тем больше размер файла с изображением. По умолчанию стоит размер 100 `dpi`. Этого вполне достаточно для отображения графика на экране монитора. Однако для демонстрации на большом экране при сохранении в растровом формате или при распечатывании отчёта на бумажном носителе лучше увеличить это значение до 200 или 300 точек на дюйм.
- `transparent` — параметр, определяющий прозрачность контейнера визуализации. Такой эффект доступен для растрового формата `png`. В расширении `jpg` установить прозрачность не получится, поскольку этот формат не поддерживает такой опции. Значение `True` — позволяет сделать график прозрачным, тогда как значение `False`, используемое по умолчанию, делает контейнер с изображением непрозрачным и по умолчанию — белым.

Например, сохраним график с разрешением 300 DPI и включённой прозрачностью:
```python
plt.savefig("my_first_plot.png", dpi=300, transparent=True)
```

### Сохранение сабплотов и проблема пересечения элементов графика

Иногда для отображения результатов аналитики используют несколько графиков на одной визуализации. Или несколько «сабплотов». При сохранении таких графиков есть свои особенности. Поскольку в одном графике включается несколько, то общий размер контейнера со всеми графиками увеличивают, например, до 12 дюймов.

Рассмотрим на примере, добавим график с накопительным значением метрик для двух групп:

```
# Создание фигуры и осей для сабплотов
fig, ax = plt.subplots(nrows=1, ncols=2, figsize=(12, 5))

# Динамика кумулятивного значения метрики в группе А и В:
sns.lineplot(x='date', y='A', data=cum_avg_purchases, label='Группа А', ax=ax[0])
sns.lineplot(x='date', y='B', data=cum_avg_purchases, label='Группа B', ax=ax[0])

# Добавим форматирование графика:
```

## Формат данных JSON
Мы уже касались данной темы в дополнительных материалах предыдущего модуля.

JSON (JavaScript Object Notation) стал неотъемлемой частью современного анализа данных. Это текстовый формат, который используется для представления структурированных данных и который основан на синтаксисе JavaScript.

JSON стал популярным благодаря своей простоте, лёгкости и читабельности как для человека, так и для машины. В мире данных JSON используется повсеместно, и умение работать с ним считается важным навыком для аналитика данных.

В этом уроке вы узнаете, как использовать библиотеку `json` для конвертации объектов Python в JSON-строку и обратно. Обсудим конкретные случаи, когда аналитику данных нужно работать с JSON. Этот урок поможет вам освоить базовые техники работы с таким форматом данных.

В Python JSON-объекты очень схожи со словарями (dict), что облегчает их использование. Рассмотрим некоторые ключевые моменты:

- **структура:** JSON представляет собой пары «ключ-значение», что аналогично структуре словаря в Python;
- **типы данных:** JSON поддерживает простые типы данных, такие как строки, числа, массивы (списки в Python), и вложенные объекты (словари в Python);
- **чтение и запись:** в Python существует встроенная библиотека **`json`**, которая предоставляет простые методы для преобразования данных между JSON- и Python-объектами.

Пример словаря в Python:

```
data = {
    "name": "John",
    "age": 30,
    "city": "New York",
    "children": ["Ann", "Billy"]
} 
```

Эквивалент в JSON:

```
{
    "name": "John",
    "age": 30,
    "city": "New York",
    "children": ["Ann", "Billy"]
} 
```

### **В каких случаях аналитику нужно работать с данными в формате JSON**

1. **Веб-API:** Большинство современных веб-API возвращают данные в формате JSON. Если аналитик взаимодействует с API для получения данных, например, от социальных сетей, финансовых сервисов или метеорологических служб, ему потребуется умение читать и обрабатывать JSON. **Пример JSON-ответа от API социальной сети:**
    
    ```
     {
         "user": {
             "id": 12345,
             "name": "John Doe",
             "followers": 150,
             "posts": [
                 {
                     "id": 54321,
                     "content": "Hello, world!",
                     "likes": 10,
                     "comments": [
                         {"id": 1, "user": "Alice", "text": "Great post!"},
                         {"id": 2, "user": "Bob", "text": "Thanks for sharing!"}
                     ]
                 }
             ]
         }
     }
      
    ```
    
2. **Хранение и передача данных:** JSON широко используется для хранения конфигураций и настроек, а также для передачи данных между различными системами. Это делает JSON незаменимым для интеграции данных из разных источников и систем. **Пример JSON-файла конфигурации:**
    
    ```
     {
         "app_name": "DataAnalyzer",
         "version": "1.2.3",
         "settings": {
             "theme": "dark",
             "auto_save": true,
             "language": "en"
         }
     }
      
    ```
    
3. **Базы данных NoSQL:** Многие современные базы данных NoSQL, такие как MongoDB, используют формат, схожий с JSON (BSON). Понимание JSON помогает аналитику эффективно работать с такими базами данных. **Пример документа в базе данных MongoDB:**
    
    ```
     {
         "_id": {"$oid": "507f1f77bcf86cd799439011"},
         "name": "Jane Smith",
         "email": "jane.smith@example.com",
         "age": 28,
         "address": {
             "street": "123 Maple Street",
             "city": "Springfield",
             "state": "IL",
             "postalCode": "62704"
         },
         "orders": [
             {"id": 1, "product": "Laptop", "quantity": 1, "price": 1200.00},
             {"id": 2, "product": "Mouse", "quantity": 2, "price": 25.00}
         ]
     }
      
    ```
    

Освоение работы с JSON даёт аналитику возможность решать широкий спектр задач, от получения данных через API до их хранения и последующей обработки. Далее мы рассмотрим, как преобразовывать объекты Python в JSON и обратно, что считается основой для дальнейшей работы с этим форматом.

### **Преобразование объектов Python в JSON**

Для преобразования объектов Python (например, словарей и списков) в JSON-строку используется функция **`json.dumps()`** из встроенной библиотеки **`json`**.

Пример:

```
import json

# Создаём объект в формате словаря Python
data = {
    "name": "Alice",
    "age": 25,
    "city": "London",
    "languages": ["English", "Spanish"]
}

# Преобразуем объект в JSON-строку
json_string = json.dumps(data)
print(json_string) 
```

Итоговый результат:

```
{"name": "Alice", "age": 25, "city": "London", "languages": ["English", "Spanish"]} 
```

### **Преобразование JSON-строки в объект Python**

Для преобразования JSON-строки обратно в объект Python используется функция **`json.loads()`**.

Пример:

```
import json

# Определим JSON-строку
json_string = '{"name": "Alice", "age": 25, "city": "London", "languages": ["English", "Spanish"]}'

# Преобразуем JSON-строку в объект Python
data = json.loads(json_string)
print(data)
# Выводим тип данных полученного объекта
print(f'Тип данных: {type(data)}') 
```

Итоговый результат:

```
{'name': 'Alice', 'age': 25, 'city': 'London', 'languages': ['English', 'Spanish']}
Тип данных: <class 'dict'> 
```

Умение преобразовывать объекты Python в JSON и обратно считается важным навыком для аналитика данных. Это позволяет эффективно работать с данными, полученными из различных источников: веб-API, базами данных и файлами конфигураций.

Внутри JSON-строки мы использовали двойные кавычки для обозначения текста — это единственный возможный вариант, другие дадут ошибку. Если двойная кавычка есть внутри передаваемой строки, то используется экранирование.

Далее мы рассмотрим более сложные примеры работы с JSON, включая вложенные структуры данных и их обработку.

### Работа с многоуровневыми JSON-объектами

Примеры, которые мы рассматривали ранее, были достаточно простыми. В реальной работе аналитикам данных часто приходится сталкиваться с более сложными и многоуровневыми JSON-объектами. Такие структуры могут содержать вложенные списки и словари, что усложняет их преобразование и анализ.

Рассмотрим пример многоуровневого JSON-объекта, который может быть получен, например, из API социальной сети. В зависимости от структуры JSON-объекта будет меняться и конкретный способ преобразования, но структура объектов обычно похожа на такую:

```
posts_data = []

for post in data['user']['posts']:

            "comment_user": comment['user']
        }
        
        # Добавляем информацию о посте
        comment_info.update(post_info)
        
        # Добавляем запись в список
        posts_data.append(comment_info)

display(posts_data)
```
