# Получение и сохранение данных
## Работа с файлами
В процессе работы бывает нужно проанализировать произвольные файлы с текстовой информацией или поработать с файлами внутри архива. В этом уроке мы узнаем, как функция `open` помогает читать и записывать файлы, научимся работать с файловой системой, а также поймём, как работать с архивными файлами через модуль `zipfile`. Это поможет понять, как аналитики могут организовывать и хранить данные.

### Открываем файлы

Функция `open` в Python используется для открытия файла. Она обращается к файловой системе и создаёт объект, который предоставляет методы для чтения или записи. Эта функция принимает два основных аргумента: имя файла и режим открытия, такой как `'r'` (read) для чтения, `'w'` (write) для полной перезаписи содержимого файла или его создания, `'a'` (append) для того, чтобы добавить содержимое в конец файла. Открыть и прочитать содержимое небольшого файла можно так:

```
file = open('example.txt', 'r')
content = file.read()
print(content)
file.close() 
```

В этом случае после чтения содержимого файла связанный с ним объект необходимо закрыть вызовом `file.close()` для освобождения системных ресурсов. Так вы показываете программе, что больше не будете обращаться к файлу.

Конструкция `with...as` упрощает управление файлами, обеспечивая автоматическое закрытие файла после выхода из блока `with`. Это делает код более чистым и безопасным:

```
with open('example.txt', 'r') as file:
    content = file.read()
    print(content) 
```

Этот код имеет такое же действие, как и код выше. Здесь файл автоматически закрывается после завершения чтения, и не нужно беспокоиться о закрытии файла вручную.

### Создаём текстовый файл

Иногда бывает необходимо создать файл с произвольным содержимым и сохранить его на диск. Откроем и перезапишем или создадим файл при помощи функции`open` в режиме записи (`"w"`) и сохраним в него имеющийся у нас текст:

```
content = """Ежедневный отчёт по продажам:
Дата: 21 мая 2024 года
Общее количество продаж: 150
Общая сумма продаж: 25,000

Основные категории товаров:
1. Электроника - 50 продаж
2. Одежда - 30 продаж
3. Бытовая техника - 70 продаж

Замечания:
- Увеличение продаж бытовой техники на 20% по сравнению с предыдущим днём.
- Снижение продаж одежды на 10%."""

with open('example.txt', 'w') as file:
    file.write(content) 
```

В данном случае создаётся файл `example.txt` и в него записывается текст из переменной `content`. Функция `write` записывает текст в файл, а использование конструкции `with...as` нужно, чтобы файл корректно закрылся после завершения записи.

### Построчная обработка данных

Не всегда полностью читать файл это хорошая идея, особенно если файл очень большой. У нас есть логи сервера `server.log`, если логи собираются за длительный срок, они могут достигать значительных объёмов. Чтобы понять, как автоматически проанализировать логи построчно, откроем такой файл со следующим содержимым:

```
2024-05-14 08:00:00 INFO Server started.
2024-05-14 08:15:23 ERROR Failed to connect to database.
2024-05-14 09:00:17 INFO New user registered.
2024-05-14 09:17:45 ERROR Timeout occurred processing request. 
```

Для того, чтобы перебрать строки файла, необходимо начать цикл, итерируясь по объекту файла. Внутри цикла мы перебираем каждую строку файла, проверяя наличие слова "ERROR". Если строка содержит это слово, она добавляется в список `errors` после удаления пробелов и символов новой строки с помощью метода `strip()`. В полученном списке подсчитываем число элементов и выводим его на экран:

```
errors = []
with open('server.log', 'r') as file:
    for line in file:
        if "ERROR" in line:
            errors.append(line.strip())

print(f"Найдено ошибок: {len(errors)}") 
```

```
Всего ошибок в логах: 2 
```

### Открываем много файлов

Не всегда мы знаем точно название файла, который нам нужно открыть. Также, зачастую в процессе работы приходится иметь дело не с одним и не с двумя файлами, а с большим их количеством. Например, каждый день филиал присылает файл, имя которого начинается с `report_` и заканчивается на `.xlsx` и нам нужно обработать все эти файлы. Сначала найдём все такие файлы. В этом нам поможет библиотека `os`. Её метод `listdir` позволяет получить содержимое указанной папки. Строкой из одной точки обычно обозначается текущая папка.

```
import os

reports = [f for f in os.listdir('.') 
            if f.startswith('report_') and f.endswith('.xlsx')] 
```

В переменную `reports` теперь помещён список названий файлов `['report_2024-05-06.xlsx', 'report_2024-05-07.xlsx', 'report_2024-05-08.xlsx', 'report_2024-05-09.xlsx', 'report_2024-05-10.xlsx']` с названиями ежедневных отчётов за предыдущую неделю. Теперь мы можем обработать их в цикле необходимым образом.

Для открытия отчётов нам потребуется метод Pandas `read_excel`. Отчёт типовой, сверху у него шапка, снизу место для подписей сотрудников, посередине данные. Пропустить строки шапки нам поможет параметр `skiprows`, он принимает список строк, начиная с нуля, которые нужно пропустить. Пропустить окончание документа нам поможет параметр `skipfooter`, он принимает одно число — количество строк в конце документа, которые не нужно загружать.

У отчёта много объединённых ячеек и не каждый столбец содержит данные. Так как нужные нам столбцы у отчёта не меняются, мы указываем их в нотации Excel в параметре `usecols`, где можем использовать как отдельные столбцы, так и их диапазоны. После загрузки отчёта метод `set_axis` с параметром `axis=1` позволит нам задать названия столбцам загружаемого датафрейма. Важно изменять список новых названий согласованно со значением, передаваемым в `usecols`. Весь пример кода загрузки датасетов в цикле целиком:

```
import pandas as pd

# Для каждого названия файла отчёта
for report in reports:
    # Открываем файл с таблицей
    df_raw = pd.read_excel(
        report,
        # Пропускаем шапку отчёта из 35 строк
        skiprows=range(35),
        # Пропускаем последние 10 строк документа
        skipfooter=10,
        # Используем заранее известные столбцы
        usecols="K:L,AY,BF,BU,CJ")\
        .set_axis(
            # Задаём названия оси таблицы 
            [   "Раздел", 
                "Показатель", 
                "Код показателя", 
                "Текущий год", 
                "Предыдущий год", 
                "Предшествующий предыдущему"],
            # Заменяем названия колонок
            axis=1) 
```

Далее нам может потребоваться предобработка данных и расчёт каких-то показателей. Информацию можно брать не только из таблицы: само имя файла `report` у нас содержало дату — её можно извлечь и сохранить, чтобы потом анализировать динамику метрик.

### Работаем с архивами

Библиотека `zipfile` в Python предоставляет возможности для работы с ZIP-архивами, включая возможности их создания, чтения, записи, а также извлечения содержимого. Допустим, что в конце предыдущего раздела мы подготовили сводный отчёт и сохранили его на диске под названием `consolidated_report.xlsx`. Этот файл вместе с отчётами за отдельные дни нам нужно добавлять в архив. Так как предыдущие действия мы автоматизировали, попробуем автоматизировать и это! Помня, что файлы продолжают лежать в той же папке, в которой мы запускаем скрипт, сделаем это при помощи модуля `zipfile`:

```
import zipfile

with zipfile.ZipFile('reports_archive.zip', 'w', zipfile.ZIP_DEFLATED) as archive:
    for report in reports:
        archive.write(report)
    else:
        archive.write('consolidated_report.xlsx') 
```

Конструкция `else` после циклов отрабатывает в случае успешного завершения цикла. Ура, теперь всё сохранили, можем отсылать! Обратите внимание, `zipfile` по умолчанию не сжимает файлы при создании архива, поэтому мы указываем тип сжатия `zipfile.ZIP_DEFLATED`.

### Автоматизация процессов с помощью чтения ZIP-архивов

Текстовые форматы хранения данных, например формат `csv`, могут очень быстро прибавлять в объёме по мере добавления данных, но они обычно хорошо сжимаются. Очень часто такие файлы распространяются в запакованном виде.

Выше мы записывали файлы в архив, но архивы иногда бывает необходимо читать. Используем библиотеку `zipfile` для этого.

Для более надёжной и безопасной работы с файлами и архивами используем использовавшуюся выше конструкцию `with...as`, причём сделаем её вложенной. Конструкция гарантирует, что файл и архив будут корректно закрыты после завершения нужных операций.

Например, внутри архива расположен файл `purchases.csv`, который выглядит следующим образом:

```
PurchaseID,Amount
001,25.50
002,45.00
003,17.75
004,34.00 
```

Используем модуль `zipfile` для открытия архива `monthly_data.zip` с помощью конструкции `with...as`. Затем внутри архива открываем файл `purchases.csv`. Первую строку файла, содержащую заголовки, проверяем с помощью функции `next(file)` и конструкции `assert` на соответствие ожидаемому значению. В случае несоответствия заголовков `assert` выведет сообщение об ошибке. Файл для Python — это набор байтов, как и отдельные его части, поэтому мы ставим `b` перед строкой.

Используя генераторное выражение внутри функции `sum`, подсчитываем количество строк, которое соответствует количеству покупок. В конце результат выводится на экран.

```
import zipfile

# Открытие ZIP-архива и чтение содержимого CSV-файла внутри
with zipfile.ZipFile('purchases.zip', 'r') as archive:
    with archive.open('purchases.csv') as file:
        assert next(file) == b'PurchaseID,Amount\n', \
            'Заголовки файла не соответствуют ожидаемым'
        # Подсчёт количества строк и покупок
        total_purchases = sum(1 for _ in file)

print(f"Общее количество покупок: {total_purchases}") 
```

Мы научились добавлять файлы в архивы и открывать текстовые файлы в Python, даже если они запакованы. Если есть возможность импортировать библиотеку pandas и в архиве лежит всего один файл csv, то можно использовать привычный метод `read_csv`. Однако для других случаев удобно знать другие методы открытия текстовых данных.

### Запуск кода

C тем, **какой** код запускать мы разобрались, но чтобы автоматизация была удобной, надо придумать, **как** его запускать. Работа в Python может быть весьма разнообразной, как и задачи, которые решаются с его помощью.

Основными форматами файлов в Python считаются `.py`, они используются для создания и запуска собранных программ и проектов. Файлы `.ipynb` применяются для интерактивного выполнения кода и ведения журнала вычислений в удобном интерфейсе Jupyter Notebook, так как они удобнее для написания кода, особенно если его нужно кому-то передавать. Однако для запуска небольшого скрипта тетрадки Jupyter Notebook подходят хуже.

Если скрипт выше сохранён в файле `purchases.py` и на компьютере установлен Python, то достаточно в командной строке ввести `python purchases.py`, чтобы увидеть результат: `Общее количество покупок: 4`.

Вы можете использовать подходящие для вашей системы планировщики запуска скриптов для автоматизации рабочих задач.

## Работа с таблицами
Аналитика начинается с данных. Бывает, что они хранятся уже в готовых csv/tsv-файлах и вы используете метод `read_csv()`, чтобы превратить таблицы в датафреймы. Бывает, что данные хранятся в Excel-файле, но и это уже нестрашно и вы вызываете метод `read_excel()`.

Так или иначе, всё это время вы работали с таблицами, которые хранятся на вашем компьютере, перед этим скачивая их по ссылке.

Но что делать, если таблица с данными, которые вам нужны, хранится где-то в интернете, на веб-странице, а кнопки `скачать` просто нет?

### Сайты тоже хранят данные

Переходя по ссылке на любой из сайтов, ваш браузер всегда начинает с того, что скачивает файлы, это называют загрузкой сайта. Все файлы, которые скачивает браузер, делятся на несколько типов, вот самые важные:

- `html` — получая такой файл, браузер понимает, как должна выглядеть страница сайта для пользователя, и начинает её отрисовку. `html`-файл говорит браузеру, как именно нарисовать страницу сайта и что она будет содержать. По сути, это разметка с содержимым, как Markdown в jupyter-третрадке, но посложнее. Именно об этом файле мы сегодня поговорим.
- `png/jpg/gif` и прочее — это картинки, которые сопровождают вас почти всегда: логотип сайта, видеолендинг. Это называют ассетами.
- `js` — это те файлы, которые говорят браузеру, что нужно делать, когда начинаете взаимодействовать с сайтом: кликать, скроллить или печатать.

Всё содержимое страницы сайта хранится в `html`-файле, и выглядит он примерно так:

```
<!DOCTYPE html>
<html>
<head>
  <title>Мой первый веб-сайт</title>
</head>
<body>
  <header>
    <h1>Добро пожаловать на мой сайт!</h1>
    <nav>
      <ul>
        <li><a href="#">Главная</a></li>
        <li><a href="#">О нас</a></li>
        <li><a href="#">Услуги</a></li>
        <li><a href="#">Контакты</a></li>
      </ul>
    </nav>
  </header>
  
... 
```

Попробуем прочитать эти данные прямо с сайта, но используя Pandas. Для этого воспользуемся методом `read_html()`, указывая параметром только адрес URL-ссылки на страницу. Этот метод исследует html-файл страницы и пытается найти всё, что похоже на таблицу, и превратить в датафрейм. Строку подаём сразу в зашифрованном виде (`%D0%A7`…), скопировав из адресной строки браузера.

```
import pandas as pd

tables = pd.read_html('https://ru.wikipedia.org/wiki/%D0%A7%D0%B5%D0%BC%D0%BF%D0%B8%D0%BE%D0%BD%D0%B0%D1%82_%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D0%B8_%D0%BF%D0%BE_%D1%84%D1%83%D1%82%D0%B1%D0%BE%D0%BB%D1%83')
```

### Excel будет недалеко

Когда вам нужно **передать** результаты своего исследования, в котором есть таблицы, редко когда подойдёт Jupyter-тетрадка с кодом, ведь это больше инструмент аналитика данных. Вы можете сохранить таблицы в csv-файлы с помощью метода `to_csv()`, но и такой формат некоторых может насторожить. Презентуя результаты своим коллегам, стоит использовать знакомый большинству Excel.

В самом начале обучения вы знакомились с преимуществами Python перед Excel. И всё же Excel остаётся на сегодня наиболее популярным инструментом для решения простых задач. Любой, даже не аналитик, знаком с этим инструментом просто потому, что Excel есть почти у каждого, а если его и нет, то всегда можно открыть таблицу в этом формате в Google Sheets.

Вы уже знаете, как импортировать данные из Excel, а точнее из xlsx-файла, а теперь научимся сохранять данные в формате `xlsx`. Для этого в Pandas используют метод `to_excel()` с параметрами:

- `excel_writer` — файл, в который необходимо сохранить данные.
- `sheet_name` — название листа в Excel-файле. Файл может состоять из нескольких листов.
- `engine` — движок, который используется для преобразования датафрейма в `xlsx`-формат. Либо `openpyxl`, либо `xlsxwriter`. Нам потребуется `openpyxl`, используемый по умолчанию.

Продолжим исследовать результаты бенчмарк-тестов. Посмотрим, какие результаты бенчмарк-тестов в среднем у топовых производителей.

```
top_brand = (benchmarks[benchmarks['Brand'].isin(['Apple', 'Samsung', 'Xiaomi', 'Google', 'Oppo', 'Huawei'])]
             .groupby('Brand')
             .agg({'Score': 'mean'})
             .sort_values(by='Score', ascending=False))
```

### Итоги

- Данные могут храниться не только в файлах, а ещё и на веб-страницах в виде HTML-таблиц. Вы можете читать данные не только из csv- или Excel-файлов, но и прямо из html.
- Метод `pd.read_html()` позволяет извлекать такие таблицы напрямую с веб-страниц по их URL.
- Показывать коллегам результаты работы лучше в том виде, с которым они привыкли работать. Несмотря на преимущества Python, Excel по-прежнему остаётся популярным инструментом для работы с данными.
- Чтобы сохранить данные в виде Excel-файла, используют метод `to_excel()`.
