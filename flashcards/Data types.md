Основные типы данных
?
**Числовые**
- `int` — целые числа (`42`, `-10`, `0`)
- `float` — числа с плавающей точкой (`3.14`, `-0.001`)
- `complex` — комплексные числа (`3+4j`)
**Строки**
- `str` — строки (`"Привет"`)
**Логический**
- `bool` — булевый (`True`, `False`)
**Коллекции**
- `list` — списки`[1, 2, 3]`
- `tuple` — кортежи `(1, 2, 3)`
- `set` — множества `{1, 2, 3}`
- `dict` — словари `{"name": "Alice", "age": 25}`

Основные математические операторы в `Python`  
?
`+` – сложение чисел (`int`, `float`, `complex`), конкатенация строк (`str`) и списков (`list`)
`-` – вычитание чисел (`int`, `float`, `complex`)
`*` – умножение чисел (`int`, `float`, `complex`); повторение последовательностей (`str`, `list`, `tuple`) на целое число
`/` – деление чисел с результатом `float` (`int`, `float`, `complex`)
`//` – целочисленное деление для чисел (`int`, `float`)
`**` – возведение в степень для чисел (`int`, `float`, `complex`)
`%` – остаток от деления для чисел (`int`, `float`), а также форматирование строк в старом стиле (`str` с шаблоном)

Старый стиль форматирования строк в `Python`  
?
Использует оператор `%` и плейсхолдеры внутри строки (`%s`, `%d`, `%f` и т.д.): `"Привет, %s" % name`

Основные способы форматирования строк в `Python`  
?
1) Старый стиль: `"Hi, %s" % name`  
2) Метод `.format()`: `"Hi, {}".format(name)`  
3) f‑строки: `f"Hi, {name}"`

Форматирование строк через `.format()`  
?
Использует строку-шаблон с `{}` и метод `.format()`: `"Привет, {}!".format(name)`

Форматирование чисел во `f`‑строках  
?
Можно использовать те же спецификаторы, что и в `.format()`: `f"Pi: {pi:.2f}"` → `Pi: 3.14`

Что делают поразрядные (битовые) операции в `Python`?  
?
Работают с отдельными битами целых чисел (`int`), применяя логические операции к каждому разряду по отдельности

Поразрядное И/*AND* (`&`)
?
Каждый бит результата равен `1` только если соответствующие биты обоих операндов равны `1`, иначе `0`
Например: 
`2 & 5` -> `2` = `010`, 5 = `101` -> результат `000`, в десятичной системе это `0`
`4 & 5` -> `4` = `100`, 5 = `101` -> результат `100`, в десятичной системе это `4`

Поразрядное ИЛИ/*OR* (`|`)
?
Каждый бит результата равен `1`, если хотя бы один из соответствующих битов операндов равен `1`, иначе `0`
Например:
`2 | 5` -> `2` = `010`, `5` = `101` -> результат `111`, в десятичной системе это `7`
`4 | 5` -> `4` = `100`, `5` = `101` -> результат `101`, в десятичной системе это `4`

Поразрядное исключающее ИЛИ/*XOR* (`^`)
?
Каждый бит результата равен `1`, если соответствующие биты операндов различаются, и `0`, если равны
Например: 
`9 ^ 5` -> `9` = `1001`, `5` = `0101` -> результат `1100`, в десятичной системе это `12`

Поразрядная инверсия (`~`)
?
Инвертирует все биты числа; в терминах арифметики равна выражению `-(x + 1)`
Например:
`~5` -> `~5` = `-6`, так как `~x` эквивалентно `-(x + 1)`

Почему *XOR* (`^`) подходит для простого шифрования?  
?
Потому что `x ^ key ^ key == x`: повторное применение *XOR* с тем же ключом возвращает исходное значение

Простой пример шифрования *XOR* в `Python`  
?
`encrypt = x ^ key` — шифрование, `decrypt = encrypt ^ key` — расшифровка того же значения

Как с помощью *XOR* обменять значения двух переменных без временной переменной?  
?
Выполнить:  
`x = x ^ y`  
`y = x ^ y`  
`x = x ^ y`  
После этого `x` и `y` поменяются местами

Операция сдвига влево `x << y`
?
Сдвигает биты числа `x` влево на `y` позиций, добавляя нули справа; эквивалентно умножению на `2**y` для целых
Например: 
`4 << 1` -> 4 = `100`; сдвиг влево на 1 разряд = `1000`, в десятичной системе это `8`
`16 << 2` -> 16 = `10000`; сдвиг влево на 2 разряда = `1000000`, в десятичной системе это `64`
Сдвиг числа, не кратного 2:
22 = `10110`; `22 << 2` -> `1011000`, в десятичной системе это `88`

Операция сдвига вправо `x >> y`
?
Сдвигает биты числа `x` вправо на `y` позиций; для положительных целых эквивалентно целочисленному делению на `2**y`
Например: 
`16 >> 1` -> 16 = `10000`; сдвиг вправо на 1 разряд = `1000`, в десятичной системе это `8`
`16 >> 2` -> 16 = `10000`; сдвиг вправо на 2 разряда = `100`, в десятичной системе это `4`
Сдвиг числа, не кратного 2:
22 = `10110`; `22 >> 2` = `101`, в десятичной системе это `5`

Как можно интерпретировать сдвиг для положительных целых чисел?  
?
`x << n` примерно как умножение на `2**n`, `x >> n` — как целочисленное деление на `2**n` (для неотрицательных `int`)

Как в `Python` обозначается принадлежность числа к двоичной, восьмеричной и шестнадцатеричной системам счисления?
?
Двоичная — `0b`, восьмеричная — `0o`, шестнадцатеричная — `0x`

Каким образом в `Python` можно вставить значения переменных в строку и какой символ ставится перед строкой для этого?
?
Перед строкой ставится символ `f`, а переменные размещаются в фигурных скобках `{}`

Зачем нужны преобразования типов в `Python`?  
?
Чтобы можно было выполнять операции между значениями разных типов (например, `int` и `float`) или преобразовывать данные из строк в числа и обратно.

По какому правилу выбирается тип результата при арифметике, если участвуют `int` и `float`?  
?
Если один из операндов `float`, другой не выше по «иерархии», то оба приводятся к `float`, и результат тоже `float`.

Что происходит, если в арифметической операции участвует `complex` и другое число?  
?
Другой операнд неявно приводится к `complex`, и операция выполняется в комплексной арифметике.

Что происходит в выражении `a + b`, если `a = 2 (int)`, `b = 2.5 (float)`?  
?
Происходит неявное приведение `a` к `float`, операция выполняется как `2.0` + `2.5`, результат `4.5`.

Что произойдёт при:
```python
a = "2"
b = 3
c = a + b
```
?
Будет ошибка `TypeError`, потому что нельзя сложить строку и число: интерпретатор не знает, выполнять ли сложение или конкатенацию.

Как обойти ошибку, если нужно получить число `5` из `"2"` и `3`?  
?
Явно преобразовать строку в int: `c = int(a) + b`.

Какие стандартные функции используются для явного преобразования базовых типов?  
?
`int()` — к целому числу, `float()` — к числу с плавающей точкой, `str()` — к строке.

Какие строки нельзя преобразовать через `int` и `float`, и что произойдёт?  
?
Строки, которые не являются целым десятичным числом, например `"a1c"` или `"4.7"`, вызовут `ValueError`.

Почему выражение
```python
age = 22
message = "Age: " + age
```
вызывает ошибку?  
?
Потому что нельзя конкатенировать строку и число, требуется строка + строка.

Чем различаются операции сложения для чисел и строк?  
?
Для чисел `+` — арифметическое сложение, для строк `+` — конкатенация (объединение строк).

Когда `Python` выполняет неявные преобразования типов в арифметике?  
?
Когда операнды совместимы: например, `int` с `float` → оба к `float`, `int` с `complex` → оба к `complex`.
