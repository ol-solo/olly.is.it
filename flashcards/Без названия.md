Что такое переменные и зачем они нужны?
?
Переменные в программировании — это основа любого кода. Представьте их как ярлыки или контейнеры, которые хранят информацию. В Python переменная создаётся в момент, когда вы впервые присваиваете ей значение.

Главные преимущества переменных:
1. **Повторное использование данных** — один раз сохранили значение и используем многократно
2. **Читаемость кода** — осмысленные имена переменных делают программу понятнее
3. **Упрощение изменений** — меняем значение в одном месте, а не во всём коде

Как Python работает с переменными?
?
Python использует **систему ссылок** для работы с переменными:
- Переменная - это имя, ссылающееся на объект в памяти
- Один объект может иметь несколько имён
- Присваивание создаёт новую ссылку, а не копию объекта
- Сборщик мусора удаляет объекты, на которые нет ссылок

Что такое динамическая типизация?
?
Динамическая типизация— это подход, при котором тип данных переменной определяется не во время компиляции, а в момент присвоения значения при выполнении программы. Это означает, что одна и та же переменная может хранить сначала число, а затем строку, что обеспечивает высокую гибкость в коде.
```python
x = 10 # Переменная x становится целым числом 
x = "Привет" # Теперь та же переменная x становится строкой
```

Что такое статическая типизация?
?
Статическая типизация — это метод, при котором переменной, параметру или функции присваивается тип данных на этапе компиляции, до запуска программы. Этот тип нельзя изменить позже, а любые несоответствия выявляются как ошибки до выполнения кода.
```java
// Явно объявляем типы данных
int age = 25; 
String name = "Алексей";
```

Основные типы переменных
?
**Числовые**
- `int` — целые числа (42, -10, 0)
- `float` — числа с плавающей точкой (3.14, -0.001)
- `complex` — комплексные числа (3+4j)
**Строки**
- `str` — строки ("Привет")
**Логический**
- `bool` — булевый (`True`, `False`)
**Коллекции**
- `list` — списки`[1, 2, 3]`
- `tuple` — кортежи `(1, 2, 3)`
- `set` — множества `{1, 2, 3}`
- `dict` — словари `{"name": "Alice", "age": 25}`

Как удалить переменную?
?

Основные математические операторы в Python  
?
`+` – сложение чисел (`int`, `float`, `complex`), конкатенация строк (`str`) и списков (`list`)
`-` – вычитание чисел (`int`, `float`, `complex`)
`*` – умножение чисел (`int`, `float`, `complex`); повторение последовательностей (`str`, `list`, `tuple`) на целое число
`/` – деление чисел с результатом `float` (`int`, `float`, `complex`)
`//` – целочисленное деление для чисел (`int`, `float`)
`**` – возведение в степень для чисел (`int`, `float`, `complex`)
`%` – остаток от деления для чисел (`int`, `float`), а также форматирование строк в старом стиле (`str` с шаблоном)

Старый стиль форматирования строк в Python  
?
Использует оператор `%` и плейсхолдеры внутри строки (`%s`, `%d`, `%f` и т.д.): `"Привет, %s" % name`
