#flashcards/python/variables/basics

Что такое объект в памяти в контексте Python?::Это ячейка памяти, в которой хранится некоторое значение (число, строка, таблица и т.п.).

Что такое ссылка на объект в Python?::Это внутренний «номер ячейки» в памяти, по которому интерпретатор находит объект.

Зачем нужны переменные, если у объекта уже есть ссылка в памяти?::Чтобы работать с данными по понятному имени вместо длинного и меняющегося адреса в памяти.

Что такое переменная в Python?::Это имя для объекта в памяти.

Как в Python объявить переменную?::Присвоить ей значение с помощью `=`: `name = value`.

Какую роль играет оператор `=` в Python?::Это оператор присваивания, он связывает имя переменной со значением справа.

Где должно находиться имя переменной относительно `=`?::Слева от `=`.

Где должно находиться значение при присваивании переменной?::Справа от `=`.

Что произойдёт, если дважды присвоить значение одной и той же переменной?::Она будет хранить последнее присвоенное значение.

Что хранит переменная `candies` после подряд идущих строк `candies = 24` и `candies = 25`?::Число `25`.

#flashcards/python/variables/print-end-sep

За что отвечает параметр `end` в функции `print()`?::Он определяет, что добавлять в конце вывода вместо стандартного `\n`.


Что выведет код:
```python

```
?

```python
print(price, product, sep=' — ')
```

Что выведет код:
```python

product = 'pizza'
print(price, product, sep=' — ')
```
?
`399 — pizza`.

Можно ли одновременно использовать `sep` и `end` в одном вызове `print()`?::Да, можно задавать и разделитель между аргументами, и окончание строки.

#flashcards/python/strings/formatting

Что такое форматирование строк в Python?::Создание строки по шаблону с подстановкой значений переменных в нужные места.

Как использовать метод `format()` для подстановки значения?::В строке пишут `{имя}`, затем вызывают `.format(имя=значение)`.

Что выведет:
```python
s = 'Я {position}'.format(position='аналитик данных')
print(s)
```
?
`Я аналитик данных`.

Как подставить несколько значений методом `format()`?::Указать несколько плейсхолдеров `{...}` в строке и передать имённые аргументы в `.format(...)`.

Что делают фигурные скобки `{}` в f-строке?::Внутрь подставляются значения выражений/переменных.

Как объявить f-строку?::Поставить `f` перед строковым литералом: `f"...{var}..."`.

Чем отличается f-строка от `format()` технически?::В f-строке подстановка делается сразу при создании строки, без отдельного вызова `.format()`.

Какой синтаксис у примера с f-строкой для отчёта?::`s = f"...{cr_percent}...{dau}...{dau_delta}..."`.

Когда форматирование особенно удобно?::Когда нужно собрать длинную текстовую строку/шаблон отчёта из нескольких переменных.

#flashcards/python/lists/basics

Что такое список в Python?::Упорядоченный набор элементов (коллекция), у которого элементы имеют индексы.

Как создаётся список литералом?::Через квадратные скобки с элементами через запятую: `[1, 2, 3]`.

Как создать пустой список?::`empty_list = []`.

Могут ли элементы списка иметь разные типы данных?::Да, в одном списке могут быть `str`, `int`, `float` и другие типы.

Что такое вложенный список?::Список, элементы которого сами являются списками.

Пример вложенного списка::`items_list = [[1, 2, 3], [1, 2, 3, 4], [5, 6]]`.

Какой тип данных у объекта списка?::`list`.

Что выведет `print(type([1994, 1972, 2008]))`?::`<class 'list'>`.

Как узнать количество элементов в списке?::Через `len(list_name)`.

#flashcards/python/lists/index-slice

С какого числа начинается индексация элементов списка?::С нуля.

Как получить первый элемент списка `years`?::`years[0]`.

Как получить последний элемент списка `first_film` с помощью отрицательного индекса?::`first_film[-1]`.

Что выведет:
```python
first_film = ['Побег из Шоушенка', 'США', 1994, 'драма', 142, 9.111]
print(first_film, first_film, first_film[-1])
```
?::`Побег из Шоушенка США 9.111`.

Что произойдёт при обращении к несуществующему индексу списка?::Будет ошибка `IndexError: list index out of range`.

Как выглядит общий формат среза списка?::`list_obj[start:end:step]`.

Что выведет:
```python
first_film[1:4]
```
для `first_film = ['Побег...', 'США', 1994, 'драма', 142, 9.111]`?::`['США', 1994, 'драма']`.

Что выведет:
```python
first_film[:3]
```
для того же списка?::`['Побег из Шоушенка', 'США', 1994]`.

Что выведет:
```python
first_film[2:]
```
?::`[1994, 'драма', 142, 9.111]`.
