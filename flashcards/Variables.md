Что такое переменные и зачем они нужны?
?
Переменные в программировании — это основа любого кода. Представьте их как ярлыки или контейнеры, которые хранят информацию. В Python переменная создаётся в момент, когда вы впервые присваиваете ей значение.

Главные преимущества переменных:
1. **Повторное использование данных** — один раз сохранили значение и используем многократно
2. **Читаемость кода** — осмысленные имена переменных делают программу понятнее
3. **Упрощение изменений** — меняем значение в одном месте, а не во всём коде

Как Python работает с переменными?
?
Python использует **систему ссылок** для работы с переменными:
- Переменная - это имя, ссылающееся на объект в памяти
- Один объект может иметь несколько имён
- Присваивание создаёт новую ссылку, а не копию объекта
- Сборщик мусора удаляет объекты, на которые нет ссылок

Что такое динамическая типизация?
?
Динамическая типизация — это подход, при котором тип данных переменной определяется не во время компиляции, а в момент присвоения значения при выполнении программы. Это означает, что одна и та же переменная может хранить сначала число, а затем строку, что обеспечивает высокую гибкость в коде.
```python
x = 10 # Переменная x становится целым числом 
x = "Привет" # Теперь та же переменная x становится строкой
```

Что такое статическая типизация?
?
Статическая типизация — это метод, при котором переменной, параметру или функции присваивается тип данных на этапе компиляции, до запуска программы. Этот тип нельзя изменить позже, а любые несоответствия выявляются как ошибки до выполнения кода.
```java
// Явно объявляем типы данных
int age = 25; 
String name = "Алексей";
```

Как удалить переменную?
?
```python
x = 10
del x
print(x)  # Вызовет ошибку NameError
```

Что такое область видимости (scope) переменной в Python?  
?
Это контекст, в пределах которого имя переменной доступно: где её можно читать и изменять.

Какие два основных типа области видимости переменных есть в Python?  
?
Глобальная область видимости и локальная область видимости (внутри функции).

Что такое глобальная переменная в Python?  
?
Переменная, определённая вне всех функций модуля; она доступна из любой функции (если не закрыта локальной с тем же именем).

Можно ли из функции читать глобальную переменную без специальных ключевых слов?  
?
Да, пока внутри этой функции нет локальной переменной с тем же именем, глобальная будет доступна на чтение.

Что такое локальная переменная в Python?  
?
Переменная, определённая внутри функции; она доступна только в этой функции и исчезает после её завершения.

Можно ли использовать локальную переменную одной функции внутри другой функции напрямую?  
?
Нет, локальные переменные видны только внутри той функции, в которой объявлены.

Что происходит, если в функции объявить переменную с тем же именем, что и глобальная?  
?
Локальная переменная с тем же именем «скрывает» глобальную внутри этой функции; обращения идут к локальной.

Что показывает пример:
```python
name = "Tom"
def say_hi():
    print("Hello", name)
def say_bye():
    print("Good bye", name)
```
?
Что обе функции `say_hi` и `say_bye` читают одно и то же глобальное значение `name`.

Что показывает пример:
```python
def say_hi():
    name = "Sam"
    surname = "Johnson"
    print("Hello", name, surname)
def say_bye():
    name = "Tom"
    print("Good bye", name)
```
?
Что `name` в `say_hi` и `name` в `say_bye` — разные локальные переменные, а `surname` доступна только внутри `say_hi`.

Что показывает пример:
```python
name = "Tom"
def say_hi():
    name = "Bob"
    print("Hello", name)
def say_bye():
    print("Good bye", name)
```
?
Что `say_hi` использует локальное имя `name = "Bob"`, а `say_bye` — глобальное `name = "Tom"`.

Для чего в функции используется ключевое слово `global`?  
?
Чтобы сообщить, что имя относится к глобальной переменной, и изменения внутри функции должны затронуть именно её, а не создать локальную.

Что делает пример:
```python
name = "Tom"
def say_hi():
    global name
    name = "Bob"
    print("Hello", name)
def say_bye():
    print("Good bye", name)
```
?
В `say_hi` изменяется глобальная переменная `name` на `"Bob"`, и обе функции затем используют уже обновлённое значение.

Что делает вложенная функция `inner` в примере:
```python
def outer():
    n = 5
    def inner():
        print(n)
    inner()
    print(n)
```
?
Она читает и выводит значение `n` из внешней функции `outer`; оба раза будет напечатано 5.

Что происходит в примере:
```python
def outer():
    n = 5
    def inner():
        n = 25
        print(n)
    inner()
    print(n)
```
?
В `inner` создаётся новая локальная `n = 25`, которая скрывает внешнюю `n`; поэтому `inner` выводит 25, а `outer` по-прежнему выводит 5.

Для чего используется ключевое слово `nonlocal` во вложенной функции?  
?
Чтобы указать, что имя переменной относится к ближайшей внешней (неглобальной) области видимости, а не создаёт новую локальную переменную.

Что делает пример:
```python
def outer():
    n = 5
    def inner():
        nonlocal n
        n = 25
        print(n)
    inner()
    print(n)
```
?
`nonlocal n` привязывает `n` во вложенной функции к переменной `n` из `outer`; присваивание `n = 25` изменяет внешнюю `n`, и оба вывода будут 25.

Чем отличаются `global` и `nonlocal`?  
?
`global` привязывает имя к переменной из глобальной области, `nonlocal` — к переменной ближайшей внешней функции (но не к глобальной).
