#flashcards/python/conditional_constructions

Оператор `==` при сравнении двух значений  
?
Возвращает `True`, если операнды равны, иначе `False`.

Оператор `!=` при сравнении двух значений  
?
Возвращает `True`, если операнды НЕ равны, иначе `False`.

Оператор `>` при сравнении двух значений  
?
Возвращает `True`, если первый операнд больше второго.

Оператор `<` при сравнении двух значений  
?
Возвращает `True`, если первый операнд меньше второго.

Оператор `>=` при сравнении двух значений  
?
Возвращает `True`, если первый операнд больше или равен второму.

Оператор `<=` при сравнении двух значений  
?
Возвращает `True`, если первый операнд меньше или равен второму.

Как работает оператор `and` с булевыми выражениями?  
?
Возвращает `True`, только если оба операнда истинны; иначе `False`.

Как работает оператор `or` с булевыми выражениями?  
?
Возвращает `True`, если хотя бы один операнд истинен.

Как работает оператор `not`?  
?
Возвращает `True`, если выражение ложно, и `False`, если выражение истинно.

Что делает оператор `in`?  
?
Проверяет, содержится ли значение в некотором наборе значений (последовательности, коллекции и т.п.), возвращает `True` или `False`.

Что делает оператор `not in`?  
?
Проверяет, что значение отсутствует в наборе значений, возвращает `True` или `False`.

Что делает условная конструкция `if` в *Python*?  
?
Проверяет логическое выражение и в зависимости от его результата направляет выполнение программы по одному из возможных путей.

Как выглядит общий синтаксис конструкции `if` в *Python* (с необязательными частями)?  
?
```python
if логическое_выражение:
	инструкции
elif логическое_выражение:
	инструкции
else:
	инструкции
```

Для чего в конструкции `if` используется блок `else`?  
?
Чтобы определить альтернативный блок инструкций, который выполняется, если условие в `if` (и все условия `elif`, если они есть) оказалось ложным.

Для чего используется ключевое слово `elif` в *Python*?  
?
Для проверки дополнительных альтернативных условий, если предыдущие условия `if`/`elif` оказались ложными.

Как работает цепочка `if` / `elif` / `else` при выполнении?  
?
*Python* последовательно проверяет условие в `if`; если оно `False` — проверяет первое `elif`, затем следующее и т.д.; при первом истинном условии выполняет соответствующий блок и остальные блоки пропускает.

Можно ли использовать несколько блоков `elif` в одной конструкции?  
?
Да, можно добавить сколько угодно блоков `elif`, каждый со своим условием.

Что происходит, если ни одно условие `if`/`elif` не оказалось истинным, а блок `else` есть?  
?
Выполняется блок `else`, как «ветка по умолчанию».

Что происходит, если ни одно условие `if`/`elif` не оказалось истинным, а блока `else` нет?  
?
Никакой из блоков не выполняется, программа просто пропускает всю конструкцию и переходит к выполнению следующего кода, идущего после нее.

Какие два основных вида циклов есть в *Python*?  
?
Цикл `while` и цикл `for`.

Для чего нужны циклы в программах?  
?
Чтобы многократно выполнять блок кода, пока выполняется условие или пока не будут перебраны все элементы набора значений.

Как выглядит общий синтаксис цикла `while` в *Python*?  
?
```python
while условное_выражение:
	инструкции
```

Как работает цикл `while`?  
?
Пока условие после `while` возвращает `True`, выполняется блок инструкций цикла; когда условие становится `False`, цикл завершается.

Что называется итерацией цикла?  
?
Однократное выполнение всего тела цикла от начала до конца.

Что делает пример:
```python
number = 1
while number < 5:
    print(number)
    number += 1
```
?
Он выводит числа `1`, `2`, `3`, `4`, по одному на строку, затем цикл завершается при `number == 5`.

Для чего у цикла `while` может использоваться блок `else`?  
?
Код в блоке `else` выполняется один раз после завершения цикла, когда условие стало `False` и цикл естественно завершил работу.

Как выглядит общий синтаксис цикла `for` в *Python*?  
?
```python
for переменная in набор_значений:
	инструкции
```

Как работает цикл `for`?  
?
Он последовательно перебирает все значения из набора, по очереди присваивает их переменной и выполняет тело цикла для каждого значения.

Что в *Python* может выступать в роли «набора значений» для `for`?  
?
Строка, список, кортеж, диапазон `range()` и другие итерируемые объекты.

Для чего используется функция `range()` в цикле `for`?  
?
Для генерации последовательности целых чисел, по которой затем итерируется цикл `for`.

Как интерпретируется один параметр в `range(10)`?  
?
Это верхняя граница диапазона (не включительно); последовательность будет от `0` до `10`, не включая `10`.

Что делает `range(4, 10)` в цикле `for`?  
?
Генерирует числа от `4` до `9` включительно.

За что отвечает третий аргумент в `range(0, 10, 2)`?  
?
За шаг приращения; здесь шаг `2`, поэтому генерируются числа `0`, `2`, `4`, `6`, `8`.

Какой вывод даёт цикл:
```python
for n in range(0, 10, 2):
    print(n, end=" ")
```
?
Он выводит: `0 2 4 6 8`.

Когда выполняется блок `else` у цикла `for`?  
?
После завершения нормальной работы цикла `for`, когда перебраны все элементы набора и цикл закончился без принудительного выхода.

Что такое вложенный цикл?  
?
Цикл, расположенный внутри тела другого цикла; внутренний цикл выполняется полностью для каждой итерации внешнего.

Для чего используется оператор `break` в цикле?  
?
Для немедленного выхода из цикла (`while` или `for`), даже если условие цикла ещё истинно или есть не перебранные элементы.

Что делает пример:
```python
number = 0
while number < 5:
    number += 1
    if number == 3:
        break
    print(number)
```
?
Цикл увеличивает number, печатает `1` и `2`, при `number == 3` выполняет `break` и выходит из цикла; числа `3`, `4`, `5` не выводятся.

Для чего используется оператор `continue` в цикле?  
?
Для пропуска оставшейся части тела текущей итерации и перехода к следующей итерации цикла.

Что делает пример:
```python
number = 0
while number < 5:
    number += 1
    if number == 3:
        continue
    print(number)
```
?
При `number == 3` выполняется continue, строка с `print` пропускается; в итоге выводятся числа `1`, `2`, `4`, `5`.

Чем принципиально отличается `break` от `continue`?  
?
`break` полностью прерывает цикл и выходит из него, а `continue` только прерывает текущую итерацию, переходя к следующей проверке условия или следующему элементу.

Каким образом определяется принадлежность инструкций к циклу `while` в языке *Python*?
?
Принадлежность инструкций к циклу `while` определяется отступами от начала ключевого слова `while`.

Что произойдёт, если условие в цикле `while` изначально будет равно `False`, и как в этом случае может быть использован блок `else`?
?
Цикл не выполнит ни одной итерации и сразу перейдёт к блоку `else`
