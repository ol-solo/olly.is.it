#flashcards/python/functions

Что такое функция в `Python`?  
?
Функция — это именованный блок кода, который выполняет определённую задачу и который можно вызывать многократно из разных мест программы.

Зачем вообще выносить код в функции?  
?
Чтобы избежать дублирования кода, улучшить читаемость программы и удобно переиспользовать логику в разных местах.

Как выглядит общее формальное определение функции в `Python`?  
?
```python
def имя_функции([параметры]):
	инструкции
```

С какой конструкции начинается определение функции?  
?
С ключевого слова `def`, за которым следуют имя функции, круглые скобки (с параметрами или без) и двоеточие.

Что такое локальная (внутренняя) функция?  
?
Это функция, определённая внутри другой функции; она доступна только внутри этой внешней функции.

Можно ли вызвать локальную функцию снаружи той функции, внутри которой она объявлена?  
?
Нет, её имя видно только внутри внешней функции, снаружи она недоступна.

Зачем в `Python`-программе вводят функцию `main`?  
?
Чтобы собрать основную логику программы в одном месте и вызывать из неё другие функции, упорядочивая структуру кода.

Что делает следующий шаблон:
```python
def main():
    say_hello()
    say_goodbye()
def say_hello():
    print("Hello")
def say_goodbye():
    print("Good Bye")
main()
```
?
Определяет три функции, а затем запускает программу с вызова `main()`, внутри которой по очереди вызываются `say_hello` и `say_goodbye`.

Почему удобно запускать программу через `main()`, а не сразу вызывать разные функции в глобальной области видимости?  
?
Так проще контролировать точку входа в программу, читать код и при необходимости изменять порядок вызовов или добавлять новую логику.

Что обычно делает функция `main()`?  
?
Оркестрирует выполнение: вызывает другие функции, организует общий порядок шагов программы.

Почему удобно вызывать `main()` в самом конце файла?  
?
Потому что выше можно разместить все определения функций и вспомогательный код, а в `main()` — только последовательность вызовов.

Как выглядит типичный шаблон с `main()` и проверкой точки входа?  
?
```python
def main():
    say_hello()
    say_goodbye()

def say_hello():
    print("Hello")

def say_goodbye():
    print("Good Bye")

if __name__ == "__main__":
    main()
```

Что означает проверка `if __name__ == "__main__"`: ?  
?
Код внутри этого блока выполняется только при запуске файла как самостоятельного скрипта, но не при импорте его как модуля.

Зачем функции нужны параметры?  
?
Через параметры функция принимает данные «снаружи», чтобы работать не только с зашитым внутри значением, а с разными входными данными.

Как в определении функции записываются параметры?  
?
В круглых скобках после имени функции: `def func(param1, param2):`.

Что делает функция:
```python
def say_hello(name):
    print(f"Hello, {name}")
```
?
Она принимает один параметр `name` и выводит приветствие с этим именем.

Что такое значение параметра по умолчанию?  
?
Это значение, которое параметр получает автоматически, если при вызове функции ему не было явно передано аргумента.

Как объявить параметр со значением по умолчанию?  
?
Указать `имя=значение` в определении функции, например: `def say_hello(name="Tom"):`.

Что делает пример:
```python
def say_hello(name="Tom"):
    print(f"Hello, {name}")
say_hello()
say_hello("Bob")
```
?
При первом вызове `name` будет `Tom` (значение по умолчанию), при втором — `Bob`.

Какое правило порядка для обязательных и необязательных параметров в определении функции?  
?
Обязательные параметры должны идти в списке параметров раньше параметров со значениями по умолчанию.

Что означает «передача аргументов по имени» при вызове функции?  
?
Аргумент передаётся в конкретный параметр, указанным по имени, например: `print_person(age=22, name="Tom")`.

В чём преимущество передачи аргументов по имени?  
?
Можно не соблюдать порядок параметров в вызове и сделать код более читаемым, явно подписывая, что есть что.

Для чего в определении функции используется символ `*` перед параметрами?  
?
Чтобы указать, что все параметры справа от `*` могут получать значения только по имени (*keyword-only* аргументы).

Что означает сигнатура:
```python
def print_person(name, *, age, company):
    ...
```
?
`name` можно передавать позиционно, а `age` и `company` должны передаваться только по имени.

Можно ли сделать все параметры функции *keyword-only*?  
?
Да, если поставить `*` и затем перечислить параметры, например: `def func(*, name, age, company):`.

Для чего в определении функции используется символ `/`?  
?
Чтобы указать, что все параметры слева от `/` являются позиционными только и не могут получать значения по имени.

Что означает сигнатура:
```python
def print_person(name, /, age, company="Microsoft"):
    ...
```
?
`name` — строго позиционный параметр, `age` можно передавать и по позиции, и по имени, `company` имеет значение по умолчанию и может быть именованным аргументом.

Почему нельзя вызвать такую функцию как `print_person(name="Tom", age=24)`?  
?
Потому что `name` объявлен как *positional-only* (до `/`), и его нельзя передавать по имени.

Что означает сигнатура:
```python
def print_person(name, /, age=18, *, company):
    ...
```
?
`name` — только позиционный, `age` можно передавать и по позиции, и по имени (плюс есть значение по умолчанию), `company` должен передаваться только по имени.

Чем отличаются группы параметров до `/`, между `/` и `*`, и после `*`?  
?
До `/` — только позиционные; между `/` и `*` — можно передавать и по позиции, и по имени; после `*` — только *keyword-only*.

Что означает запись параметра с одной звездочкой, например `*numbers`?  
?
Что функция может принять произвольное количество позиционных аргументов, которые внутри собираются в кортеж `numbers`.

Как работает функция:
```python
def sum(*numbers):
    result = 0
    for n in numbers:
        result += n
    print(f"sum = {result}")
```
?
Она принимает любое число числовых аргументов, складывает их в цикле и выводит сумму.

Почему `*numbers` внутри функции ведёт себя как набор значений, по которому можно пройтись циклом `for`?  
?
Потому что все переданные позиционные аргументы собираются в кортеж `numbers`, и его можно итерировать.

Для чего в функции используется оператор `return`?  
?
Чтобы вернуть значение из функции вызвавшему коду и одновременно завершить выполнение функции.

Как выглядит общий синтаксис использования `return` в функции?  
?
```python
def имя_функции ([параметры]):
    инструкции
    return возвращаемое_значение
```

Чем принципиально отличается `print(...)` от `return ... `внутри функции?  
?
`print` только выводит значение и «забывает» его, а `return` передаёт значение наверх, чтобы его можно было сохранить и использовать дальше.

Что делает функция:
```python
def double(number):
    return 2 * number
```
?
Она возвращает удвоенное значение аргумента `number`, вычисляя выражение `2 * number`.

Что происходит с выполнением функции после срабатывания оператора `return`?  
?
Функция немедленно прекращает работу, и код после `return` в этом вызове больше не выполняется.

Почему инструкция после return в примере:
```python
def get_message():
    return "Hello METANIT.COM"
    print("End of the function")
```
никогда не выполняется?  
?
Потому что `return` завершает функцию до того, как интерпретатор дойдёт до `print("End of the function")`.

Можно ли использовать `return` без значения?  
?
Да, `return` без выражения просто завершает функцию и формально возвращает `None`.

Для чего использовать `return` в середине функции, а не только в конце?  
?
Чтобы сделать ранний выход из функции, когда достигнуто нужное условие (например, некорректные данные или найден ответ).

Что делает этот фрагмент:
```python
def print_person(name, age):
    if age > 120 or age < 1:
        print("Invalid age")
        return
    print(f"Name: {name}  Age: {age}")
```
?
Если возраст вне диапазона (меньше `1` или больше `120`), функция выводит `"Invalid age"` и сразу заканчивается; иначе выводит имя и возраст.

Что возвращает функция в `Python`, если внутри неё нет ни одного оператора `return`?  
?
Она неявно возвращает значение `None`.

Чем по смыслу отличается `return` без значения от отсутствия `return` в функции?  
?
Оба варианта в итоге возвращают `None`, но явный `return` используется как осознанный ранний выход в конкретной точке функции.

Что означает фраза «в `Python` функция — это тоже отдельный тип»?  
?
Функция — это объект, который можно присвоить переменной, передать как аргумент в другую функцию и вернуть из функции, как число или строку.

Как присвоить функцию переменной и потом вызвать её через переменную?  
?
```python
def say_hello(): print("Hello")
message = say_hello
message()  # вызов функции через переменную
```

Что показывает пример:
```python
def say_hello(): print("Hello")
def say_goodbye(): print("Good Bye")
message = say_hello
message()
message = say_goodbye
message()
```
?
Что одна и та же переменная `message` может по очереди ссылаться на разные функции и вызывать их, как обычные функции.

Можно ли таким образом через переменную вызывать функции с параметрами и получать результат?  
?
Да, переменная будет вести себя как имя функции, её можно вызвать с аргументами и использовать возвращаемое значение.

Что означает «функция как параметр»?  
?
Что функция может принимать другую функцию в виде аргумента и вызывать её внутри себя.

Что делает функция:
```python
def do_operation(a, b, operation):
    result = operation(a, b)
    print(f"result = {result}")
```
?
Она принимает два числа и функцию `operation`, вызывает `operation(a, b)` и выводит результат.

Что произойдёт при вызовах:
```python
def sum(a, b): return a + b
def multiply(a, b): return a * b
do_operation(5, 4, sum)
do_operation(5, 4, multiply)
```
?
В первом случае будет вычислена и выведена сумма `5` и `4` (`result = 9`), во втором — произведение (`result = 20`).

Зачем передавать функцию как параметр?  
?
Чтобы делать поведение функции гибким: одна и та же оболочка (например, `do_operation`) может выполнять разные операции, в зависимости от того, какую функцию ей передали.

Что значит, что функция возвращает другую функцию?  
?
Оператор `return` может вернуть не только число или строку, но и сам объект функции, которую потом можно вызвать.

Что делает функция:
```python
def select_operation(choice):
    if choice == 1:
        return sum
    elif choice == 2:
        return subtract
    else:
        return multiply
```
?
Она по значению `choice` возвращает одну из функций: `sum`, `subtract` или `multiply`.

Что происходит в примере:
```python
def select_operation(choice):
    if choice == 1:
        return sum
    elif choice == 2:
        return subtract
    else:
        return multiply

operation = select_operation(1)
print(operation(10, 6))
```
?
`select_operation(1)` возвращает функцию `sum`, переменная `operation` ссылается на `sum`, и вызов `operation(10, 6)` фактически равен `sum(10, 6)`.

Что произойдёт при:
```python
def select_operation(choice):
    if choice == 1:
        return sum
    elif choice == 2:
        return subtract
    else:
        return multiply

operation = select_operation(2)
print(operation(10, 6))
operation = select_operation(3)
print(operation(10, 6))
```
?
Сначала `operation` станет ссылкой на `subtract` и вернёт `4`, затем — на `multiply` и вернёт `60`.

Почему такие функции называют «высшими» (*higher-order functions*)?  
?
Потому что они работают с другими функциями: могут принимать функции как параметры и возвращать функции как результат.

Какой общий паттерн даёт «функция как параметр / результат»?  
?
Можно отделить «каркас» алгоритма (обход, вывод, обработка) от конкретной операции, передавая нужную операцию извне или выбирая её по условию.

Что такое лямбда-выражение в `Python`?  
?
Это маленькая анонимная функция, определяемая через ключевое слово `lambda` без использования `def`.

Как выглядит формальное определение лямбда-выражения?  
?
`lambda [параметры]: выражение`, где справа от двоеточия — единственное выражение, результат которого возвращается.

Чем лямбда-выражение отличается от обычной функции, определённой через `def`?  
?
Лямбда — анонимная и может содержать только одно выражение; обычная функция имеет имя и может содержать несколько операторов и более сложный код.

Что делает лямбда-выражение:
`square = lambda n: n * n`
?
Определяет анонимную функцию, которая принимает число `n` и возвращает его квадрат `n * n`.

Что делает лямбда-выражение:
`sum = lambda a, b: a + b`
?
Принимает два аргумента `a` и `b` и возвращает их сумму `a + b`.

Как в общем виде выглядят параметры у лямбда-выражения?  
?
Идут после `lambda` через запятую, например: `lambda x, y, z: выражение`.

Какое главное ограничение у лямбда-выражения по сравнению с обычной функцией?  
?
Оно может содержать только одно выражение, нельзя писать несколько операторов, циклы и т.п. как отдельные строки.

В каких случаях лямбда-выражения особенно удобны?  
?
Когда нужно быстро описать небольшую функцию «на месте»: передать её как параметр или вернуть из другой функции, не создавая отдельную именованную функцию через `def`.

Как использовать лямбда-выражение вместо функции:
```python
def do_operation(a, b, operation):
    result = operation(a, b)
    print(f"result = {result}")
```
?
Передать его прямо в вызове: `do_operation(5, 4, lambda a, b: a + b)`.

Что делает функция:
```python
def select_operation(choice):
    if choice == 1:
        return lambda a, b: a + b
    elif choice == 2:
        return lambda a, b: a - b
    else:
        return lambda a, b: a * b
```
?
В зависимости от значения `choice` возвращает одну из трёх анонимных функций: сложение, вычитание или умножение.

В каком порядке необходимо определять и вызывать функцию в `Python`?
?
Сначала определить функцию, затем вызвать её

Как передаются значения параметрам функции при её вызове, если не используются именованные параметры?
?
По позиции

Каким образом можно сделать параметр функции необязательным?
?
Указать значение по умолчанию при определении функции

Что такое замыкание (`closure`) в `Python`?  
?
Это функция, которая запоминает своё лексическое окружение (переменные внешней функции) и может использовать его даже после завершения внешней функции.

Из каких трёх частей состоит замыкание?  
?
1) Внешняя функция с локальными переменными/параметрами.  
2) Эти переменные и параметры — лексическое окружение.  
3) Вложенная функция, которая использует это окружение.

Что делает функция outer в примере:
```python
def outer():
    n = 5
    def inner():
        nonlocal n
        n += 1
        print(n)
    return inner
```
?
Создаёт локальную переменную `n`, определяет внутреннюю функцию `inner`, которая изменяет `n`, и возвращает эту внутреннюю функцию.

Что содержит переменная `fn` после вызова `fn = outer()`?
```python
def outer():
    n = 5
    def inner():
        nonlocal n
        n += 1
        print(n)
    return inner
```
?
Ссылку на внутреннюю функцию `inner` вместе с её лексическим окружением, где `n` из `outer` привязан к этому замыканию.

Что выведут последовательные вызовы:
```python
fn()
fn()
fn()
```
если `fn = outer()`?  
?
Сначала `6`, затем `7`, затем `8`.

Почему значение `n` «помнится» между вызовами `fn()`?  
?
Потому что `n` хранится во внешнем замкнутом окружении, связанном с `inner`; каждый вызов изменяет это сохранённое значение, а не создаёт новое.

Зачем во внутренней функции `inner` использовать `nonlocal n`?  
?
Чтобы явно указать, что `n` берётся из окружающей функции `outer` и при присваивании не создаётся новая локальная переменная.

Что будет, если убрать `nonlocal n` и оставить только локальное присваивание?
```python
def outer():
    n = 5
    def inner():
        n = 25
        print(n)
    return inner
```
?
Во внутренней функции появится новая локальная `n`, которая не изменит `n` из `outer`, и это перестанет быть корректным «счётчиком» поверх внешней переменной (каждый вызов всегда выводит `25`).

Почему без `nonlocal inner` при присваивании `n = n + 1` выдаёт ошибку `UnboundLocalError`?
```python
def outer():
    n = 5
    def inner():
        n += 1
        print(n)
    return inner
```
?
Потому что интерпретатор считает `n` локальной (из-за присваивания), но при этом она используется до инициализации в самой `inner`.

Какие три компонента включает в себя замыкание?
?
Внешняя функция, лексическое окружение, вложенная функция

Как изменяется значение переменной `n` при последовательных вызовах функции `fn()` в примере с замыканием?
```python
def outer():
    n = 5   
  
    def inner():     
        nonlocal n
        n += 1      
        print(n)
  
    return inner

fn = outer()
fn()   
fn()  
fn()
```
?
Значение переменной `n` увеличивается на `1` при каждом вызове `fn()`.

Что такое декоратор в `Python`?  
?
Это функция, которая принимает другую функцию как аргумент и возвращает новую функцию, обычно оборачивая поведение исходной.

Зачем использовать декораторы?  
?
Чтобы модифицировать поведение функции (логика до/после вызова, проверка аргументов, постобработка результата) без изменения её исходного кода.

Как синтаксически применяется декоратор к функции?  
?
Перед определением функции пишут `@имя_декоратора` на строке выше `def`, например:
```python
@select
def hello(): ...
```

Что делает декоратор `select` в примере:
```python
def select(input_func):
    def output_func():
        print("*****************")
        input_func()
        print("*****************")
    return output_func
```
?
Он принимает функцию `input_func`, создаёт обёртку `output_func`, которая печатает строки до и после вызова `input_func`, и возвращает эту обёртку

Что означает запись:
```python
@select
def hello():
    print("Hello METANIT.COM")
```
?
К функции `hello` применяется декоратор `select`, поэтому при вызове `hello()` на самом деле выполняется возвращённая `output_func`.

Что фактически происходит, когда интерпретатор обрабатывает `@select` над `hello`?
```python
@select
def hello():
    print("Hello METANIT.COM")
```
?
Функция `hello` передаётся в `select` как аргумент, `select` возвращает `output_func`, и имя `hello` привязывается к этой новой функции-обёртке.

Зачем во внутренней функции декоратора часто используют `*args` (и иногда `**kwargs`)?  
?
Чтобы принять все позиционные (и, при необходимости, именованные) аргументы оригинальной функции и затем передать их дальше в неё.

Что делает декоратор:
```python
def check(input_func):
    def output_func(*args):
        input_func(*args)
    return output_func
```
?
Он принимает любую функцию `input_func`, создаёт обёртку `output_func`, которая получает те же аргументы и просто передаёт их в `input_func`.

Как работает пример:
```python
@check
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")
print_person("Tom", 38)
```
?
Вызов `print_person("Tom", 38)` приводит к вызову обёртки `output_func("Tom", 38)`, которая передаёт аргументы в оригинальную `print_person`, и на консоль выводится `Name: Tom  Age: 38`.

Как в декораторе можно изменить аргументы до вызова оригинальной функции?  
?
Принять их через `*args` (и/или `**kwargs`), обработать или скорректировать значения, а затем вызвать исходную функцию с изменёнными аргументами.

Что делает декоратор:
```python
def check(input_func):
    def output_func(*args):
        name = args[0]
        age = args[1]
        if age < 0:
            age = 1
        input_func(name, age)
    return output_func
```
?
Он перехватывает имя и возраст, заменяет отрицательный возраст на `1` и только потом вызывает исходную функцию с уже скорректированным возрастом.

Что выведет код:
```python
@check
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")
print_person("Tom", 38)
print_person("Bob", -5)
```
?
Сначала `Name: Tom  Age: 38`, затем `Name: Bob  Age: 1` — отрицательный возраст был заменён на `1` внутри декоратора.

Как декоратор может получить и изменить возвращаемое значение функции?  
?
Внутри обёртки вызвать исходную функцию, сохранить результат в переменную, при необходимости изменить его, затем вернуть новое значение.

Что делает декоратор:
```python
def check(input_func):
    def output_func(*args):
        result = input_func(*args)
        if result < 0:
            result = 0
        return result
    return output_func
```
?
Он вызывает исходную функцию, получает результат, и если результат меньше нуля — заменяет его на `0`, затем возвращает это значение.

Что делает пример:
```python
@check
def sum(a, b):
    return a + b
result1 = sum(10, 20)
result2 = sum(10, -20)
```
?
`sum(10, 20)` вернёт `30` (положительный результат остаётся без изменений), `sum(10, -20)` вернёт `0` (отрицательный результат декоратор заменяет на `0`).

Какие три вещи обычно делает декоратор?  
?
Принимает функцию как аргумент, создаёт обёртку вокруг неё (может менять аргументы и результат) и возвращает эту обёртку вместо исходной функции.

В чём практическая польза декораторов?  
?
Они позволяют добавлять повторяющуюся «обязательную» логику (валидация, логирование, кэширование, проверка прав) к функциям без изменения их исходного тела.

Что представляет собой функция-декоратор в `Python` и что она возвращает в качестве результата?
?
Функция-декоратор в `Python` возвращает новую функцию, полученную после модификации исходной.

Как применяется декоратор к функции в `Python` и какой символ используется для его обозначения?
?
Декоратор применяется к функции с помощью символа `@` перед её определением.

Как можно использовать декоратор для проверки и изменения результата функции?
?
Использовать декоратор для проверки результата и его изменения при определённых условиях.

Какие преимущества предоставляют декораторы при работе с функциями в `Python`?
?
Модификация функции, её параметров и результата без изменения исходного кода.
