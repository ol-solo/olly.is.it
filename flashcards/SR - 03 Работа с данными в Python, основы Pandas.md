## Карточки
#flashcards/python/dicts/basics

Что такое словарь (`dict`) в Python?::Коллекция пар «ключ–значение», где каждому ключу соответствует своё значение.

Чем словарь отличается от списка?::Список индексируется числами от 0, а словарь — произвольными ключами.

Как создать словарь расписаний рейсов по коду рейса?::Например:
```python
schedule = {
    'SU2222': '12.06.23 12:30',
    'SU1111': '12.06.23 14:05',
}
```

Какой тип данных у объекта `schedule`?::`dict`.

Можно ли в словаре хранить значения разных типов?::Да, значения могут быть строками, числами, списками и т.д.

---

#flashcards/python/dicts/access

Как получить значение по ключу в словаре `schedule`?::Через квадратные скобки: `schedule['SU2222']`.

Что выведет:
```python
schedule = {'SU2222': '12.06.23 12:30', 'SU1111': '12.06.23 14:05'}
print(schedule['SU2222'])
```
?::`12.06.23 12:30`.

Что произойдёт при обращении к отсутствующему ключу `schedule['DP6831']`?::Будет ошибка `KeyError: 'DP6831'`.

Как выглядит типичное сообщение об этой ошибке?::`KeyError: <имя_ключа>`.

Чем полезен тип `dict` на примере расписаний?::Позволяет быстро получить нужный рейс по его коду, без перебора всего списка.

#flashcards/python/dicts/get

Для чего используют метод `dict.get(key)`?::Для безопасного получения значения по ключу без `KeyError`.

Что вернёт `schedule.get('DP6831')`, если такого ключа нет?::`None`.

Как задать значение по умолчанию при использовании `get()`?::Передать второй аргумент: `schedule.get('DP6831', 'нет рейса')`.

Чем отличается обращение `schedule['key']` от `schedule.get('key')` при отсутствии ключа?::Первое даёт `KeyError`, второе возвращает `None` или значение по умолчанию.

#flashcards/python/dicts/nested

Можно ли использовать в качестве значения словаря список или другой словарь?::Да, словари свободно поддерживают вложенные структуры.

Пример словаря, где значением по ключу рейса является список дат вылета::Например:
```python
schedule = {
  'SU2222': ['12.06.23 12:30', '12.06.24 18:30', '12.06.25 22:30']

```

Что вернёт:
```python
print(schedule['SU2222'])
```
для такого словаря?::Список всех дат/времен рейса `SU2222`.

#flashcards/python/dicts/iteration

Что возвращает метод `dict.keys()`?::Итератор по всем ключам словаря.

Что возвращает метод `dict.values()`?::Итератор по всем значениям словаря.

Что возвращает метод `dict.items()`?::Итератор по парам `(ключ, значение)`.

Как перебрать все страны в словаре `country_capitals`?::Например:
```python
for country in country_capitals.keys():
    print(country)
```

Как перебрать все столицы в словаре `country_capitals`?::Через `.values()`:
```python
for capital in country_capitals.values():
    print(capital)
```

Как перебрать пары страна–столица?::Через `.items()`:
```python
for country, capital in country_capitals.items():
    print(country, capital)
```

#flashcards/python/dicts/search-by-value

Как найти страну по столице в словаре `country_capitals` без `.items()`?::Перебрать ключи:
```python
for country in country_capitals.keys():
    if country_capitals[country] == 'Rome':
        rome_country = country
        break
```

Как сделать то же самое с `.items()`?::Перебирать пары:
```python
for country, capital in country_capitals.items():
    if capital == 'Rome':
        rome_country = country
        break
```

Почему `items()` удобнее для поиска по значениям?::Сразу даёт и ключ, и значение без дополнительного индексирования по ключу.

#flashcards/python/dicts/mutation

Как добавить новую пару в словарь `country_capitals`?::Присвоить по новому ключу:
```python
country_capitals['USA'] = 'Washington'
```

Что делает выражение `country_capitals['Italy'] = 'Roma'`?::Создаёт или обновляет значение по ключу `'Italy'`.

Для чего служит метод `pop(key)` у словаря?::Удаляет пару по ключу и возвращает значение.

Что выведет:
```python
deleted = country_capitals.pop('Italy')
print(deleted)
print(country_capitals)
```
(логически)?::Сначала столицу `'Roma'`, затем словарь без записи про `'Italy'`.

Чем отличается `pop()` от простого `del dict[key]`?::`pop()` ещё и возвращает удалённое значение.

#flashcards/python/bigdata/list-vs-dict

Как обычно хранят пользователей в примере конспекта?::В списке, где каждый элемент — структура `userinfo` с данными пользователя.

Что делает код:
```python
orders = 0
for user in users_list:
    orders += user['orders']
```
?::Проходит по всем пользователям и суммирует их заказы.

Как растёт время выполнения такого цикла по списку, когда пользователей становится всё больше?::Пропорционально числу элементов (линейно по N). 

Почему линейный перебор списка становится проблемой при десятках миллионов записей?::Каждый проход по списку добавляет заметное время; при очень больших N суммарное время становится слишком большим. 

В чём ключевое преимущество словаря (`dict`) по сравнению со списком для поиска по идентификатору?::Доступ по ключу в среднем выполняется за постоянное время (почти мгновенно), без перебора всех элементов. 

Когда логичнее использовать словарь вместо списка для пользователей?::Когда часто нужен быстрый доступ по ключу (id пользователя) или номеру заказа, а не просто последовательный обход. 

#flashcards/python/bigdata/perf

Какой порядок сложности имеет перебор списка длины N в цикле `for user in users_list`?::Операция порядка \(O(N)\): время растёт линейно с числом элементов. 

Какой порядок сложности имеет обращение к элементу словаря по ключу `d[key]` в среднем случае?::Близко к \(O(1)\): почти не зависит от числа элементов. 

Почему при росте данных на порядок (в 10 раз) время полного перебора списка тоже растёт примерно в 10 раз?::Потому что каждый новый элемент добавляет ещё одну итерацию цикла.

Какой общий вывод по структурам данных для больших объёмов?::Нужно выбирать структуры с быстрым доступом (словари, индексы, DataFrame‑колонки), а не всегда полагаться на голые списки и полный перебор.

#flashcards/python/pandas/filter/columns-inplace

Когда оправдано использование `inplace=True`?::Когда нужно окончательно изменить исходный датафрейм и цепочка методов не требуется.

#flashcards/python/pandas/indexing/intro

Что такое индексация в контексте DataFrame?::Обращение к строкам и столбцам по их “координатам”: меткам индекса и названиям столбцов.

Какие три основных способа индексации в pandas есть?::Через `[]`, через `.loc[]` и через `.iloc[]`.

За что отвечает оператор `[]` при работе с DataFrame?::За простую индексацию по меткам столбцов и по целочисленным срезам строк.

#flashcards/python/pandas/indexing/rows-slices

Почему в срезе `music_df[0:3]` строка с индексом 3 не попадает в результат?::Потому что верхняя граница среза не включается, как в списках Python.

Что делает срез `music_df[:]`?::Возвращает полную копию датафрейма (все строки).

#flashcards/python/pandas/indexing/rows-one

Почему `music_df[9]` вызывает ошибку `KeyError`?::Потому что `[]` в таком виде ожидает имя столбца, а столбца с именем `9` нет.

Как получить только строку с индексом 9 через `[]`?::Использовать срез: `music_df[9:10]`.

Почему для одной строки тоже используют срез, а не “индекс по числу”?::Чтобы явно указать, что речь идёт о срезе строк, а не о доступе к столбцу по имени.

#flashcards/python/pandas/indexing/rows-position

Как ведёт себя `df[:5]` после сортировки индекса не по порядку?::Всё равно возвращает первые 5 строк по порядку в датафрейме, а не по значениям индекса.

Что использует оператор `[]` при срезе строк: значения меток или позицию?::Позицию (целочисленный порядковый номер строки).

Почему это важно при работе с несортированными или сложными индексами?::Потому что `df[:5]` может вернуть не те строки, которые ожидаются, если воспринимать его как срез по значениям индекса.

#flashcards/python/pandas/filter/logic-basics

Что такое логическая (булева) маска в Pandas?::Серия `True`/`False` такой же длины, как DataFrame, которую используют для отбора строк.

Как выглядит логическая маска для условия `music_df['genre'] == 'metal'`?::Серия, где строки с `genre == 'metal'` помечены `True`, остальные — `False`.

Как отфильтровать строки с жанром `metal` в `music_df`?::`music_df[music_df['genre'] == 'metal']`.

Как называется приём фильтрации строк с помощью логической маски?::Логическая индексация.

#flashcards/python/pandas/filter/logic-ops

Какие операторы сравнения можно использовать в логических масках?::`==`, `!=`, `>`, `<`, `>=`, `<=`.

Как отфильтровать строки, где `genre` не равен `'pop'`?::`music_df[music_df['genre'] != 'pop']`.

Как с помощью оператора `~` получить тот же результат, что и `!= 'pop'`?::`music_df[~(music_df['genre'] == 'pop')]`.

Что делает оператор `~` по отношению к логической маске?::Инвертирует её: `True` → `False`, `False` → `True`.

#flashcards/python/pandas/filter/logic-combine

Как выбрать строки, где жанр `metal` ИЛИ `rock`?::`music_df[(music_df['genre'] == 'metal') | (music_df['genre'] == 'rock')]`.

Почему каждое условие в сложной маске берут в круглые скобки?::Чтобы оператор `&`/`|` применялся к результатам сравнения, а не к сырым Series/строкам.

Что произойдёт, если записать без скобок:
```python
music_df['genre'] == 'metal' | music_df['genre'] == 'rock'
```::Сначала отработает `|`, получится некорректное выражение и ошибка типов.

Как выбрать строки, где жанр `jazz` и `total_play` в диапазоне от 80 до 130, одной маской?::Например:
```python
mask = (music_df['genre'] == 'jazz') & \
       (music_df['total_play'] >= 80) & \
       (music_df['total_play'] <= 130)
filtered_df = music_df[mask]
```

Зачем сохранять сложное логическое выражение в переменную `mask`?::Чтобы сделать код читаемым и легко менять условия фильтрации в одном месте.

Как применить маску `mask` к DataFrame `music_df`?::`filtered_df = music_df[mask]`.

Как вывести первые 7 строк столбцов `artist`, `genre`, `track` для маски “metal или rock”?::```python
mask = (music_df['genre'] == 'metal') | (music_df['genre'] == 'rock')
music_df[mask][:7][['artist', 'genre', 'track']]```

Почему иногда фильтрацию разбивают на несколько шагов, а не пишут одно длинное выражение?::Так проще читать код и поэтапно проверять корректность каждого условия.

#flashcards/python/pandas/filter/logic-summary

Как выглядит общий паттерн логической индексации через `[]`?::`df[логическая_маска]`, где маска — Series из `True`/`False`.

Чем логическая индексация отличается от срезов по позициям `df[a:b]`?::Срез по позициям опирается на номера строк, а логическая маска решает по условию, какие строки оставить.

Какой вариант использовать, если нужно “все строки с нужным жанром”, а не “первые N строк”?::Логическую индексацию: `df[df['genre'] == 'нужный жанр']`.

#flashcards/python/pandas/indexing/loc-iloc-intro

Каков общий синтаксис операторов `.loc[]` и `.iloc[]`?::`df.loc[строки, столбцы]` и `df.iloc[индексы_строк, индексы_столбцов]`.

Чем принципиально отличается `.loc[]` от `.iloc[]`?::.loc[] индексирует по меткам (именам) индексов и столбцов, .iloc[] — по целочисленным позициям.

Можно ли в `.loc[]` использовать логическую маску по строкам?::Да, `.loc[маска, столбцы]` — стандартный паттерн логической индексации.

#flashcards/python/pandas/indexing/loc-iloc-slices

Как с помощью `.loc[]` выбрать строки с метками 1, 2 и 3 включительно?::`music_df.loc[1:3]`.

Как с помощью `.iloc[]` выбрать строки с позициями 1, 2 и 3?::`music_df.iloc[1:4]` (правая граница не включается).

В чём отличие поведения `.loc[a:b]` и `.iloc[a:b]` по правой границе?::.loc включает метку `b`, .iloc работает как обычный срез Python и не включает `b`.

Как получить первые 3 строки DataFrame с помощью `.iloc[]`?::`df.iloc[:3]`.

#flashcards/python/pandas/indexing/loc-iloc-filtered

Что происходит с метками индекса после фильтрации `filtered_df = df[df['genre'] == 'dance']`?::Они сохраняют исходные значения (например 12, 14, 15…), а не пере-нумеруются автоматически.

Почему `filtered_df.loc[1:3]` может вернуть пустой датафрейм после фильтрации?::Потому что у строк уже нет меток 1, 2, 3 — `.loc` ищет метки, а не позиции.

Как в таком случае выбрать строки с метками в диапазоне от 14 до 18 включительно?::`filtered_df.loc[14:18]`.

Почему `filtered_df.iloc[1:4]` после фильтрации всё равно возвращает “вторую, третью, четвёртую” строки?::Потому что `.iloc` опирается только на позиции (0, 1, 2, …), которые пересчитываются в новом объекте.

#flashcards/python/pandas/indexing/reset-index

Зачем после фильтрации иногда вызывают `reset_index()`?::Чтобы пере-нумеровать индекс строк подряд от 0 и снова использовать позиционные срезы/метки.

Что делает `filtered_df = filtered_df.reset_index()` без параметров?::Добавляет новый столбец `index` со старыми метками и создаёт новый индекс 0,1,2…

Как удалить старые метки индекса при сбросе?::Использовать `reset_index(drop=True)`.

Как выглядит код, чтобы отфильтровать `genre == 'dance'` и сбросить индекс без сохранения старых меток?::```python
filtered_df = music_df[music_df['genre'] == 'dance']
filtered_df = filtered_df.reset_index(drop=True)```
