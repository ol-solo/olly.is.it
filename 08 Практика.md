# Масштабирование данных. Практика

Упорядоченные категории, представленные текстовыми данными, можно перед нормализацией или масштабированием заменить при помощи `replace`.

Пример нормализации и стандартизации:

```
from sklearn.preprocessing import StandardScaler

# нормализация:
x_norm = (x - min(x)) / (max(x) - min(x))

# стандартизация:
x_st = (x - np.mean(x)) / np.std(x)

# стандартизация библиотекой:
scaler = StandardScaler()
x_scaled = scaler.transform(x.to_frame()) 
```

StandardScaler ожидает получить на вход таблицу.

## Задание 1.

Приведены ответы 18 респондентов, которым было предложено выразить свою степень согласия с утверждениями «я люблю заниматься спортом» (признак `s`) и «мне нравится готовить» (признак `c`).

Ответы давались по шкале Ликерта, которая часто используется в опросах: варианты ответа «полностью не согласен», «скорее не согласен», «не знаю», «скорее согласен» и «полностью согласен».

Одна из переменных закодирована числами от -2 до 2 (где -2 — это «полностью не согласен», 2 — «полностью согласен»), другая представлена в текстовом виде.

Закодируйте числами переменную, которая представлена строками, нормализуйте оба признака и выведите на экран средние значения нормализованных признаков в предложенном формате.

При кодировании учтите, что шкала Ликерта предполагает равное расстояние между числами, так как смысловое расстояние между вариантами одинаково. Например, можно закодировать признак `с` числами от 1 до 5 с шагом в 1 или числами от 30 до 70 с шагом в 10.

```python
import numpy as np
import pandas as pd
  
s = pd.Series([1, 2, -1, 0, 2, 1, -1, -1, -1, 1, 0, -1, 2, 0, 1, 2, 1, 2])
c = pd.Series(['не знаю', 'скорее согласен', 'полностью согласен', 'скорее согласен', 'полностью не согласен',
     'не знаю', 'скорее не согласен', 'скорее согласен', 'полностью согласен', 'полностью не согласен',
     'не знаю', 'скорее согласен', 'полностью не согласен', 'не знаю', 'скорее согласен',
     'полностью согласен', 'скорее не согласен', 'скорее не согласен'])
  
code = {
    'полностью не согласен': 1,
    'скорее не согласен': 2,
    'не знаю': 3,
    'скорее согласен': 4,
    'полностью согласен': 5,
}
  
c_coded = c.replace(code)
  
s_normalized = (s - s.min()) / (s.max() - s.min())
c_normalized = (c_coded - c_coded.min()) / (c_coded.max() - c_coded.min())
  
print("Среднее значение нормализованной s:", s_normalized.mean())
print("Среднее значение нормализованной c:", c_normalized.mean())
```

# Понижение размерности. Практика

## Задание.

Чтобы создать модель, которая реализует понижение размерности методом главных компонент, можно использовать код `model = PCA(n)`. В нём `n` — это желаемое количество компонент в выводе модели.

Для отображения получившихся точек в условных координатах можно использовать метод `scatter` из библиотеки `matplotlib`.

Модель PCA возвращает объект numpy ndarray — он похож на датафреймы pandas, но не содержит индекса. Обратиться к первому столбцу такого массива можно, используя оператор индексирования: `[:, 0]`. Как и у оператора loc, первая позиция внутри квадратных скобок отвечает за строки, а вторая за столбцы. Такая запись означает, что вам нужны все строки и только первый столбец.

Примените `PCA` из `sklearn` к табличным данным `X` о винах и сожмите их до двух столбцов. Визуализируйте полученные точки. Цветом покажите сорт вина, для этого используйте переменную `y`.

```python
import numpy as np
from sklearn.datasets import load_wine
from sklearn.decomposition import PCA
from matplotlib import pyplot as plt
  
X, y = load_wine(return_X_y=True)
  
pca = PCA(2)
  
X_pca = pca.fit_transform(X)
  
plt.figure(figsize=(6, 5))
plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='viridis', s=20, alpha=0.7)
plt.xlabel('PC1')
plt.ylabel('PC2')
plt.title('Wine dataset: PCA (2 компоненты)')
plt.colorbar(label='Сорт вина')
plt.show()
```

# Кластеризация. Практика

## Задание.

Перед вами датасет отзывов пользователей онлайн-сервиса _TripAdvisor_. В нём средние оценки мест отдыха в Азии от путешественников.

Ваша задача — кластеризовать оценки мест. Это значит, что нужно:

- прочитать данные;
- стандартизировать признаки;
- задать модель на основании алгоритма K-means c числом кластеров n=3;
- спрогнозировать группы отзывов;
- получить средние значения признаков по полученным кластерам методом groupby();
- нарисовать на графиках попарного сочетания признаков получившиеся кластеры (для перебора пар признаков в прекоде вызываем функцию _combinations_ из _itertools_);
- подумать, какие выводы можно сделать.

```python
import pandas as pd
  
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt
  
# читаем данные
travel = pd.read_csv('/datasets/tripadvisor_review_case.csv')
print(travel.shape)
  
# понижаем размерность исходных данных для графика
points = PCA(2).fit_transform(travel)
  
# стандартизируем данные
sc = StandardScaler()
x_sc = sc.fit_transform(travel)
  
# задаём модель k_means с числом кластеров 3
km = KMeans(n_clusters=3, random_state=42)
# прогнозируем кластеры для наблюдений (алгоритм присваивает им номера от 0 до 2)
labels = km.fit_predict(x_sc)
travel['cluster_km'] = labels
  
# выводим статистику по средним значениям признаков по кластеру
clusters = travel.groupby('cluster_km').mean(numeric_only=True)
print(clusters.T)
  
# строим график
plt.scatter(points[:, 0], points[:, 1], c=labels, alpha=0.5)
plt.title('Кластеры в условных координатах пониженной размерности')
plt.show()
```

Метрика силуэта рассчитывается так: `silhouette_score(X, labels)`, где `X` — численные признаки, которые были использованы для кластеризации, а `labels` — метки кластеров.

Посчитайте метрику силуэта для кластеризации отзывов на _TripAdvisor._

